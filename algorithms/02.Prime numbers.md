# Prime Numbers – Short Notes for Problem Solving

## 1. **Definition**
A **prime number** is a natural number greater than 1 that has exactly **two distinct divisors**: 1 and itself.
Examples: 2, 3, 5, 7, 11, 13, 17...

---

## 2. **Prime Factorization**
Breaking a number into a product of its prime components.
- Unique for every number (Fundamental Theorem of Arithmetic).
- Example: 84 = 2 × 2 × 3 × 7.

Use cases:
- Solving LCM, GCD problems.
- Counting divisors.
- Finding coprimes.

---

## 3. **Checking if a Number is Prime (Optimized)**
### Basic optimization rules:
1. If `n <= 1` → not prime.
2. If `n <= 3` → prime.
3. If `n % 2 == 0` or `n % 3 == 0` → not prime.
4. Check only numbers up to `sqrt(n)`.
5. Check numbers of the form **6k ± 1**.

### Why 6k ± 1?
Every integer is of the form:
- 6k, 6k+1, 6k+2, 6k+3, 6k+4, 6k+5

Except 6k±1:
- Others are divisible by 2 or 3.
  Thus all primes > 3 must be in **6k ± 1**.

Not all 6k±1 are prime, but they are the only *possible* primes.

This eliminates ~66% of candidates.

---

## 4. **Sieve of Eratosthenes**
Efficient method to find all primes ≤ n.

Algorithm:
1. Create boolean array `isPrime[0..n]`, mark all true initially.
2. Starting from p = 2, mark multiples of p as composite.
3. Move to next unmarked number.
4. Stop at p * p > n.

Time complexity: **O(n log log n)**
Space: O(n)

Use cases:
- Precomputing primes
- Fast factorization
- Prime-counting problems

---

## 5. **Segmented Sieve**
Used when n is large (up to 10^12).

Idea:
- Pre-sieve primes up to sqrt(n).
- Use them to mark composites in blocks.

---

## 6. **Prime Properties Useful in Problem Solving**
### 6.1. All primes > 3 are of the form **6k ± 1**
Reason: other forms are divisible by 2 or 3.

### 6.2. Only even prime is **2**
All other even numbers are composite.

### 6.3. No prime > 3 is divisible by 3
If sum of digits % 3 == 0 → not prime.

### 6.4. Prime gaps increase with n
Useful in reasoning about density of primes.

### 6.5. Product of any two primes > 2 is odd
Because all primes > 2 are odd.

## 7. **Fast Prime-Related Formulas**
### 7.1. Counting Divisors
If n = p₁^a × p₂^b × ...
Total divisors = (a+1)(b+1)...

### 7.2. Euler's Totient Function φ(n)
Count of integers ≤ n coprime with n.
φ(n) = n × Π(1 − 1/p)

### 7.3. Sum of Divisors
For n = p₁^a × p₂^b × ...
σ(n) = Π[(p^(a+1) − 1)/(p − 1)]

## 8. **Probabilistic Tests for Very Large Numbers**
Used when n is extremely large (64-bit).
- Miller–Rabin Primality Test
- Fermat Primality Test (less reliable)

Time complexity: O(k log³ n)

---

## 9. **Common Prime-Related Observations**
- No prime ends in 0,2,4,5,6,8 except 2 and 5.
- Palindromic numbers with even digit count (except 11) are composite.
- Any number of form a^n ± b^n can be tested with known factorization formulas.
- Many contest problems revolve around prime factorization and gcd.

---

## 10. Quick Checklist for Prime Problems
A practical checklist you can use before solving ANY prime-related problem:

### 📌 When checking if a number is prime
- If n < 2 → not prime
- If n == 2 or n == 3 → prime
- If n % 2 == 0 or n % 3 == 0 → composite
- Check divisors only up to √n
- Check only numbers of the form 6k ± 1
- Stop early when i * i > n

### 📌 When generating primes up to N
- If N ≤ 10⁷ → Sieve of Eratosthenes
- If N > 10⁷ → Segmented Sieve
- If many queries → Precompute SPF (Smallest Prime Factor array)
- Avoid boolean arrays if memory tight → bitsets

### 📌 When doing factorization
- Pre-sieve primes up to √N
- Divide n by each prime until remainder becomes 1
- Remaining number > 1 → prime factor
- Use formulae:
    - No. of divisors = (a₁+1)(a₂+1)…
    - φ(n) = n × Π(1 − 1/pᵢ)

### 📌 When queries are large (10¹² to 10¹⁸)
- Use Miller–Rabin primality test (deterministic bases for 64-bit)
- Use Pollard’s Rho for factorization
- Use modular multiplication to avoid overflow

### 📌 When handling ranges [L, R]
- If R − L ≤ 10⁶ → Segmented Sieve
- Precompute primes up to √R
- Mark multiples in the range
- Handle case when L = 1 (1 is not prime)

### 📌 When solving DSA/CP problems
- Use π(n) approximation for estimating prime counts
- Use totient for gcd/counting coprimes
- Use modular arithmetic for large prime operations
- Skip unnecessary checks using 6k ± 1 jump
- Precompute everything possible before testcases

## 13. **Formulas and Prime Theorems**

### 13.1 Prime Counting Function π(n)
Approximation:
```
π(n) ≈ n / ln(n)
```
Prime Number Theorem:
```
π(n) ~ n / log n
```

### 13.2 Density of Primes
Probability a random number ≤ n is prime ≈ 1 / ln(n)

### 13.3 Twin Prime Conjecture
Twin primes: (p, p+2)
Examples: (3,5), (5,7), (11,13), (17,19)

(Not proven): Infinitely many twin primes exist.

### 13.4 Harmonic Sum of Primes
```
Σ (1/p) diverges like log log n
```
(Mertens theorem)

### 13.5 Euler’s Totient Formula
For n = Π pᵢ^{aᵢ}:
```
φ(n) = n × Π (1 − 1/pᵢ)
```

### 13.6 Wilson’s Theorem
```
(n−1)! ≡ -1 (mod n)  ⇔ n is prime
```
(Naive but theoretical.)

### 13.7 Fermat’s Little Theorem
If p is prime:
```
a^(p−1) ≡ 1 (mod p)
```
Used in fast primality tests.

## 14. **Problem-Solving Templates**

### 14.1 Efficient Prime Check (Up to 10¹²)
```
1. If n < 2 → not prime
2. Check divisibility by 2, 3
3. Loop i = 5 to sqrt(n), step 6:
   - check i and i+2
```

### 14.2 Generate Primes Up to n
- If n ≤ 10⁷ → normal sieve
- If n > 10⁷ → segmented sieve

### 14.3 Factorization Template
1. Precompute primes up to √n using sieve
2. Divide n by each prime
3. If remaining n > 1 → it's a prime

### 14.4 Count Divisors Template
1. Prime factorize
2. Use formula (a+1)(b+1)…

### 14.5 Find All Prime Factors for Many Queries
- Pre-sieve SPF (Smallest Prime Factor)
- Factor queries in O(log n) each
