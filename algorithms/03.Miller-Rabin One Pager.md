# Miller–Rabin Primality Test — One-Page Cheat Sheet

*(Intuition • Rules • Examples • Pseudocode — DSA & Competitive Programming)*

---

## 1. Goal

Fast primality testing for **large numbers** (up to `10^18`) by detecting **violations of prime-only
modular behavior**.

---

## 2. Fermat’s Foundation (Why This Exists)

If `n` is prime and `gcd(a, n) = 1`:

```
a^(n−1) ≡ 1 (mod n)
```

### Why this works for primes

* Every `1 ≤ a < n` has a **modular inverse**
* Multiplication permutes `{1..n−1}`
* Cancellation is valid

### Why it fails for composites

* Some numbers have **no inverse**
* Multiplication collapses values
* Fermat checks only the **final result**, not the structure

---

## 3. Key Number-Theory Fact (The Core Rule)

For a **prime** `p`:

```
x^2 ≡ 1 (mod p)
```

has **only two solutions**:

```
x ≡ 1 or x ≡ −1 (≡ p−1)
```

Anything else squaring to `1` ⇒ **composite**.

---

## 4. Rewrite the Exponent (Expose Structure)

Write:

```
n−1 = d × 2^s   (d is odd)
```

This creates a **squaring chain**:

```
a^d → a^(2d) → a^(4d) → ... → a^(n−1)
```

---

## 5. Allowed vs Forbidden Transitions (Memorize This)

### ✅ Allowed (Prime Behavior)

```
1      → 1
−1     → 1     (−1 ≡ n−1)
```

### ❌ Forbidden (Composite Proof)

```
x ≠ ±1  → 1
```

> **Reaching `1` without seeing `−1` first is impossible for primes.**

---

## 6. Why `x₀ = a^d = 1` Is Accepted

* Chain becomes: `1 → 1 → 1 → ...`
* No illegal squaring occurred
* Fermat condition is satisfied structurally

So:

```
x₀ == 1  ⇒ accept
```

---

## 7. Why `n−1` Is Special

```
−1 ≡ n−1 (mod n)
```

* Modulo arithmetic wraps around
* Code avoids negatives
* `n−1` represents `−1`

Squaring rule:

```
(n−1)^2 ≡ 1 (mod n)
```

---

## 8. Miller–Rabin Decision Rules

For a chosen base `a`:

1. Compute:

   ```
   x = a^d % n
   ```
2. If:

   ```
   x == 1 or x == n−1
   ```

   → **accept**
3. Repeat `s−1` times:

    * `x = x^2 % n`
    * if `x == n−1` → **accept**
4. Otherwise → **reject (composite)**

---

## 9. Example (Composite: 561)

```
560 = 35 × 2^4
```

Base `a = 2`:

```
2^35 % 561 = 263
263^2 % 561 = 166
166^2 % 561 = 67
67^2 % 561 = 1   ❌
```

Reached `1` without seeing `−1` → composite.

---

## 10. Example (Prime: 23)

```
22 = 11 × 2^1
```

```
2^11 % 23 = 1
```

Safe chain → prime behavior.

---

## 11. Pseudocode (Minimal)

```
function isPrime(n):
    if n < 2: return false
    if n == 2 or n == 3: return true
    if n is even: return false

    write n−1 = d × 2^s

    for a in bases:
        if a >= n: continue
        if not millerTest(a, d, s, n):
            return false
    return true
```

```
function millerTest(a, d, s, n):
    x = powmod(a, d, n)
    if x == 1 or x == n−1:
        return true

    repeat s−1 times:
        x = (x × x) % n
        if x == n−1:
            return true

    return false
```
