# GCD & LCM - One-Page Cheat Sheet

## Core Definitions
**GCD**: Largest number dividing both | **LCM**: Smallest number both divide  
**Coprime**: GCD(a,b) = 1 (not necessarily prime!)

---

## The Golden Formula ⭐
```
GCD(a,b) × LCM(a,b) = a × b  (ONLY for 2 numbers!)
LCM(a,b) = (a × b) / GCD(a,b)
```

---

## Algorithms (Memorize This!)

### Euclidean GCD - O(log n) - DEFAULT CHOICE
```java
int gcd(int a, int b) {
    while (b != 0) {
        int temp = b;
        b = a % b;
        a = temp;
    }
    return a;
}
```

### LCM - O(log n)
```java
long lcm(int a, int b) {
    return (long) a / gcd(a, b) * b;  // Divide first!
}
```

### Extended GCD - O(log n)
```java
int[] extGCD(int a, int b) {  // Returns {gcd, x, y}
    if (b == 0) return new int[]{a, 1, 0};
    int[] r = extGCD(b, a % b);
    return new int[]{r[0], r[2], r[1] - (a/b) * r[2]};
}
```

### Modular Inverse - O(log n)
```java
int modInv(int a, int m) {  // exists iff GCD(a,m)=1
    int[] r = extGCD(a, m);
    if (r[0] != 1) return -1;
    return ((r[1] % m) + m) % m;
}
```

## Key Properties (Must Know)

| Property | Formula | Example |
|----------|---------|---------|
| **Identity** | GCD(a,a)=a, LCM(a,a)=a | GCD(12,12)=12 |
| **With 1** | GCD(a,1)=1, LCM(a,1)=a | GCD(100,1)=1 |
| **With 0** | GCD(a,0)=a, LCM(a,0)=0 | GCD(12,0)=12 |
| **Consecutive** | GCD(n,n+1)=1 | GCD(99,100)=1 |
| **Distributive** | GCD(ka,kb)=k·GCD(a,b) | GCD(24,54)=6·GCD(4,9) |
| **Euclidean** | GCD(a,b)=GCD(b,a%b) | GCD(48,18)=GCD(18,12) |
| **Coprime** | If GCD=1→LCM=a×b | GCD(8,15)=1→LCM=120 |
| **Powers** | GCD(aⁿ,bⁿ)=(GCD(a,b))ⁿ | GCD(36,81)=9=3² |
| **Prime Factor** | GCD=∏pᵢ^min(aᵢ,bᵢ) | 60=2²×3×5, 90=2×3²×5 |
|  | LCM=∏pᵢ^max(aᵢ,bᵢ) | GCD=30, LCM=180 |

## Problem Recognition (Fast!)

| See This → Use This | Code Pattern |
|---------------------|--------------|
| "simplify", "reduce" → **GCD** | `{num/g, den/g}` |
| "meet again", "sync" → **LCM** | `lcm(periods)` |
| "largest tile", "square" → **GCD** | `gcd(length, width)` |
| "distribute equally" → **GCD** | `gcd(items)` for groups |
| "ax≡b (mod m)" → **ModInv** | Check `gcd(a,m)==1` first |
| "coprime", "no common" → **GCD=1** | `gcd(a,b)==1` |
| "array GCD/LCM" → **Iterate** | Break early if GCD=1 |

## Array Operations

```java
// GCD of array - O(n log max)
int gcdArray(int[] arr) {
    int g = arr[0];
    for (int i = 1; i < arr.length; i++) {
        g = gcd(g, arr[i]);
        if (g == 1) break;  // Early exit!
    }
    return g;
}

// LCM of array - O(n log max)
long lcmArray(int[] arr) {
    long l = arr[0];
    for (int i = 1; i < arr.length; i++) {
        l = lcm((int)l, arr[i]);
    }
    return l;
}
```

## Special Cases & Formulas

// Simplify fraction
int g = gcd(num, den);
fraction = {num/g, den/g};  // Now coprime

// Solve: ax ≡ b (mod m)
int g = gcd(a, m);
if (b % g != 0) return -1;  // No solution
x = (b/g) * modInv(a/g, m/g) % (m/g);

// Check coprime
boolean coprime = gcd(a, b) == 1;

// Euler's Totient (count coprimes ≤ n)
φ(n) = n × ∏(1 - 1/p) for all prime p|n

## Critical Mistakes to Avoid

| ❌ WRONG | ✅ CORRECT | Why |
|---------|-----------|-----|
| `(a*b)/gcd(a,b)` | `a/gcd(a,b)*b` | **Overflow!** |
| GCD×LCM = a×b×c | Only for 2! | Breaks for 3+ |
| `modInv(a,m)` | Check gcd=1 | May not exist |
| Brute force O(n) | Euclidean O(log n) | Too slow |

## Complexity Quick Check

```
gcd(a,b)           → O(log min(a,b))
lcm(a,b)           → O(log min(a,b))
gcdArray(n items)  → O(n log max)
modInverse(a,m)    → O(log min(a,m))
```

## Common Patterns (Code Templates)

### Pattern 1: Simplification
```java
int[] simplify(int num, int den) {
    int g = gcd(num, den);
    return new int[]{num/g, den/g};
}
```

### Pattern 2: Meeting Time
```java
long meetingTime(int period1, int period2) {
    return lcm(period1, period2);
}
```

### Pattern 3: Max GCD Removing One Element
```java
// Build prefix/suffix GCD arrays
prefix[i] = gcd(prefix[i-1], arr[i]);
suffix[i] = gcd(suffix[i+1], arr[i]);
// Try removing each: gcd(prefix[i-1], suffix[i+1])
```

## Twin Primes & Related
**Twin Primes**: Differ by 2 → (3,5), (5,7), (11,13), (17,19)...  
**Form**: (6k-1, 6k+1) for k≥1  
**Cousin Primes**: Differ by 4 → (3,7), (7,11)  
**Sexy Primes**: Differ by 6 → (5,11), (7,13)

## Pre-Contest Checklist
- [ ] GCD: `while(b!=0)` loop memorized?
- [ ] LCM: Divide a by gcd FIRST (overflow!)
- [ ] ModInv: Check `gcd(a,m)==1` before computing
- [ ] Array GCD: Early break if result becomes 1
- [ ] Product formula: Only for 2 numbers!
- [ ] Edge cases: a=0, b=0, negative numbers
- [ ] Use `long` for LCM results

---

## Memory Aids
**GCD** = "What they SHARE" → MIN powers → Breaks DOWN  
**LCM** = "Where they MEET" → MAX powers → Builds UP  
**Coprime** = GCD=1 (doesn't mean prime!)  
**ModInv exists** ⟺ GCD(a,m)=1
