## Part 1: Fundamental Concepts

### What is GCD (Greatest Common Divisor)?

**Intuitive Definition**: The largest number that divides both numbers without leaving a remainder.

**Formal Definition**: For integers a and b, GCD(a, b) is the largest positive integer d such that:
- d divides a (a = k₁ × d for some integer k₁)
- d divides b (b = k₂ × d for some integer k₂)

**Building Intuition**:

```
Example: GCD(12, 18)

Step 1: Find all divisors
  Divisors of 12: {1, 2, 3, 4, 6, 12}
  Divisors of 18: {1, 2, 3, 6, 9, 18}

Step 2: Find common divisors
  Common: {1, 2, 3, 6}

Step 3: Pick the greatest
  GCD(12, 18) = 6
```

**Visual Analogy - Building Blocks**:
```
12 items: ████████████ 
Can group into: 1s, 2s, 3s, 4s, 6s, or 12s

18 items: ██████████████████
Can group into: 1s, 2s, 3s, 6s, 9s, or 18s

Largest common grouping: 6 items per group
  12 = 2 groups of 6 ●●●●●● | ●●●●●●
  18 = 3 groups of 6 ●●●●●● | ●●●●●● | ●●●●●●
```

**Real-World Examples**:

1. **Gift Baskets**: 36 apples, 48 oranges → GCD(36,48)=12 baskets, each with 3 apples and 4 oranges

2. **Tile Pattern**: 48cm × 108cm floor → GCD(48,108)=12cm square tiles

3. **Gear Teeth**: Finding when same teeth align → uses GCD to simplify

### What is LCM (Least Common Multiple)?

**Intuitive Definition**: The smallest positive number that both numbers divide into evenly.

**Formal Definition**: For integers a and b, LCM(a, b) is the smallest positive integer m such that:
- a divides m (m = k₁ × a)
- b divides m (m = k₂ × b)

**Building Intuition**:

```
Example: LCM(4, 6)

Step 1: List multiples
  Multiples of 4: {4, 8, 12, 16, 20, 24, 28, ...}
  Multiples of 6: {6, 12, 18, 24, 30, ...}

Step 2: Find common multiples
  Common: {12, 24, 36, 48, ...}

Step 3: Pick the least
  LCM(4, 6) = 12
```

**Visual Analogy - Meeting Point**:
```
Bus A schedule (every 4 minutes):
|----4----|----8----|---12---|---16---|---20---|---24---|

Bus B schedule (every 6 minutes):
|------6------|------12------|------18------|------24------|

First meeting: 12 minutes
```

**Real-World Examples**:

1. **Traffic Lights**: Light A every 48s, Light B every 72s → LCM(48,72)=144s before both change together

2. **Gear Synchronization**: Gear with 24 teeth, gear with 40 teeth → LCM(24,40)=120 teeth pass before alignment

3. **Event Scheduling**: Meeting every 15 days and 20 days → LCM(15,20)=60 days until same day

### The Fundamental Relationship

**The Golden Formula**: **GCD(a, b) × LCM(a, b) = a × b**

**Why This Works**:

Think of prime factorizations:
- **GCD** takes minimum power of each prime (what they SHARE)
- **LCM** takes maximum power of each prime (where they MEET)
- Together they capture all prime factors exactly once

**Detailed Proof**:

```
Let a = p₁^a₁ × p₂^a₂ × ... × pₙ^aₙ
Let b = p₁^b₁ × p₂^b₂ × ... × pₙ^bₙ

GCD = p₁^min(a₁,b₁) × p₂^min(a₂,b₂) × ... × pₙ^min(aₙ,bₙ)
LCM = p₁^max(a₁,b₁) × p₂^max(a₂,b₂) × ... × pₙ^max(aₙ,bₙ)

For each prime pᵢ:
  min(aᵢ, bᵢ) + max(aᵢ, bᵢ) = aᵢ + bᵢ

Therefore:
  GCD × LCM = p₁^(min+max) × p₂^(min+max) × ...
            = p₁^(a₁+b₁) × p₂^(a₂+b₂) × ...
            = (p₁^a₁ × p₂^a₂ × ...) × (p₁^b₁ × p₂^b₂ × ...)
            = a × b
```

**Example**:
```
a = 12 = 2² × 3¹
b = 18 = 2¹ × 3²

GCD = 2^min(2,1) × 3^min(1,2) = 2¹ × 3¹ = 6
LCM = 2^max(2,1) × 3^max(1,2) = 2² × 3² = 36

Verify: 6 × 36 = 216 = 12 × 18 ✓

For prime 2: min(2,1) + max(2,1) = 1 + 2 = 3 = 2+1 ✓
For prime 3: min(1,2) + max(1,2) = 1 + 2 = 3 = 1+2 ✓
```

**CRITICAL**: This only works for exactly 2 numbers!

```
Counterexample for 3 numbers:
GCD(4, 6, 8) = 2
LCM(4, 6, 8) = 24
GCD × LCM = 2 × 24 = 48
Product = 4 × 6 × 8 = 192
48 ≠ 192 ✗
```

## Part 2: GCD Algorithms

### Method 1: Brute Force (Naive)

**Algorithm**: Check every number from 1 to min(a,b).

**Example**: GCD(12, 18)
```
i=1:  12%1=0 ✓, 18%1=0 ✓ → gcd=1
i=2:  12%2=0 ✓, 18%2=0 ✓ → gcd=2
i=3:  12%3=0 ✓, 18%3=0 ✓ → gcd=3
i=4:  12%4=0 ✓, 18%4=2 ✗
i=5:  12%5=2 ✗
i=6:  12%6=0 ✓, 18%6=0 ✓ → gcd=6
i=7 to 12: no common divisors
Answer: 6
```

**Code**:
```java
int gcdBruteForce(int a, int b) {
    int gcd = 1;
    int min = Math.min(a, b);
    for (int i = 1; i <= min; i++) {
        if (a % i == 0 && b % i == 0) {
            gcd = i;
        }
    }
    return gcd;
}
```

**Analysis**: Time O(min(a,b)), Space O(1) - Never use in production

---

### Method 2: Optimized Brute Force

**Algorithm**: Start from min(a,b) going backwards. First match is answer.

**Example**: GCD(12, 18)
```
i=12: 12%12=0 ✓, 18%12=6 ✗
i=11: 12%11=1 ✗
...
i=6:  12%6=0 ✓, 18%6=0 ✓ → Return 6
```

**Code**:
```java
int gcdOptimized(int a, int b) {
    int min = Math.min(a, b);
    for (int i = min; i >= 1; i--) {
        if (a % i == 0 && b % i == 0) {
            return i;
        }
    }
    return 1;
}
```

**Analysis**: Time O(min(a,b)) worst case, better average - Use for small numbers only

### Method 3: Euclidean Algorithm ⭐ (THE STANDARD)

**Key Insight**: GCD(a, b) = GCD(b, a mod b)

**Why It Works**:

```
Let d = GCD(a, b)
Then: a = qb + r where r = a mod b

Since d divides a and d divides b:
  d divides (a - qb) = r

So d divides both b and r
Therefore d divides GCD(b, r)

Conversely, any divisor of (b, r) also divides (a, b)

Thus: GCD(a, b) = GCD(b, r)
```

**Detailed Example**: GCD(252, 105)

```
Step 1: 252 = 2 × 105 + 42
  "252 contains 2 full copies of 105, plus 42 remainder"
  GCD(252, 105) = GCD(105, 42)

Step 2: 105 = 2 × 42 + 21
  "105 contains 2 full copies of 42, plus 21 remainder"
  GCD(105, 42) = GCD(42, 21)

Step 3: 42 = 2 × 21 + 0
  "42 is exactly 2 copies of 21, no remainder"
  GCD(42, 21) = GCD(21, 0) = 21

Answer: 21

Verify: 252 = 12 × 21 ✓, 105 = 5 × 21 ✓
```

**Another Example**: GCD(48, 18)
```
48 = 2 × 18 + 12  → GCD(48,18) = GCD(18,12)
18 = 1 × 12 + 6   → GCD(18,12) = GCD(12,6)
12 = 2 × 6 + 0    → GCD(12,6) = 6
```

**Code (Iterative)**:
```java
int gcd(int a, int b) {
    while (b != 0) {
        int temp = b;
        b = a % b;
        a = temp;
    }
    return a;
}
```

**Code (Recursive)**:
```java
int gcd(int a, int b) {
    return b == 0 ? a : gcd(b, a % b);
}
```

**Worst Case**: Consecutive Fibonacci numbers
```
GCD(89, 55) takes 10 steps
Fibonacci sequence forces maximum iterations
```

**Analysis**: Time O(log min(a,b)), Space O(1) iterative / O(log n) recursive

**Why It's Fast**: Each step reduces problem size by at least half (on average)

### Method 4: Subtraction Method (Ancient)

**Algorithm**: Keep subtracting smaller from larger until equal.

**Example**: GCD(12, 18)
```
a=12, b=18: b>a → b=18-12=6  (a=12, b=6)
a=12, b=6:  a>b → a=12-6=6   (a=6, b=6)
a=6, b=6:   equal → return 6
```

**Why It's Terrible**: GCD(100, 1) takes 99 subtractions!

**Code**:
```java
int gcdSubtraction(int a, int b) {
    while (a != b) {
        if (a > b) a = a - b;
        else b = b - a;
    }
    return a;
}
```

**Analysis**: Time O(max(a,b)), Space O(1) - Historical interest only

### Method 5: Binary GCD (Stein's Algorithm)

**Three Properties**:
1. If both even: GCD(a,b) = 2 × GCD(a/2, b/2)
2. If a even, b odd: GCD(a,b) = GCD(a/2, b)
3. If both odd: GCD(a,b) = GCD(|a-b|/2, min(a,b))

**Why It's Fast**: Bit shifts instead of expensive division

**Detailed Example**: GCD(48, 18)

```
a=48 (110000₂), b=18 (010010₂)

Phase 1: Extract common 2s
  Both even? Yes → a=24, b=9, shift=1
  a=24 even? Yes → a=12, shift=1
  a=12 even? Yes → a=6, shift=1
  a=6 even? Yes → a=3, shift=1
  a=3, b=9 both odd now

Phase 2: Subtract
  a=3, b=9: swap → a=3, b=9
  b=9-3=6 (even) → b=3
  a=3, b=3 → b=3-3=0

Phase 3: Restore 2s
  3 << 1 = 6

Answer: 6
```

**Code**:
```java
int binaryGCD(int a, int b) {
    if (a == 0) return b;
    if (b == 0) return a;
    
    int shift = 0;
    while (((a | b) & 1) == 0) {
        a >>= 1;
        b >>= 1;
        shift++;
    }
    
    while ((a & 1) == 0) a >>= 1;
    
    while (b != 0) {
        while ((b & 1) == 0) b >>= 1;
        if (a > b) {
            int temp = a; a = b; b = temp;
        }
        b = b - a;
    }
    
    return a << shift;
}
```

**Bit Operations**:
```java
a & 1     // Check if odd
a >> 1    // Divide by 2
a << 1    // Multiply by 2
a | b     // Bitwise OR
```

**Analysis**: Time O(log min(a,b)), Space O(1) - 20-30% faster than Euclidean

**When to Use**: Large numbers (>10¹⁸), performance-critical code

### Method 6: Prime Factorization

**Formula**: GCD = product of (min power of each common prime)

**Example**: GCD(60, 90)

```
60 = 2² × 3¹ × 5¹
90 = 2¹ × 3² × 5¹

Common primes: {2, 3, 5}

GCD = 2^min(2,1) × 3^min(1,2) × 5^min(1,1)
    = 2¹ × 3¹ × 5¹
    = 30
```

**Code**:
```java
Map<Integer, Integer> primeFactors(int n) {
    Map<Integer, Integer> factors = new HashMap<>();
    while (n % 2 == 0) {
        factors.put(2, factors.getOrDefault(2, 0) + 1);
        n /= 2;
    }
    for (int i = 3; i * i <= n; i += 2) {
        while (n % i == 0) {
            factors.put(i, factors.getOrDefault(i, 0) + 1);
            n /= i;
        }
    }
    if (n > 1) factors.put(n, 1);
    return factors;
}

int gcdPrimeFactor(int a, int b) {
    Map<Integer, Integer> fA = primeFactors(a);
    Map<Integer, Integer> fB = primeFactors(b);
    int gcd = 1;
    for (int p : fA.keySet()) {
        if (fB.containsKey(p)) {
            gcd *= Math.pow(p, Math.min(fA.get(p), fB.get(p)));
        }
    }
    return gcd;
}
```

**Analysis**: Time O(√a + √b), Space O(log a + log b)

**When to Use**: Need factorization anyway, multiple GCD operations, educational

## Part 3: LCM Algorithms

### Method 1: Using GCD (ALWAYS USE THIS)

**Formula**: LCM(a, b) = (a × b) / GCD(a, b)

**Example**: LCM(12, 18)
```
GCD(12, 18) = 6
LCM = (12 × 18) / 6 = 216 / 6 = 36

Verify: 36 ÷ 12 = 3 ✓, 36 ÷ 18 = 2 ✓
```

**CRITICAL: Avoid Overflow**
```java
// ❌ WRONG - can overflow
int lcm = (a * b) / gcd(a, b);

// ✅ CORRECT - divide first
long lcm = (long) a / gcd(a, b) * b;

Example: a=2000000000, b=1500000000
  a*b = 3×10¹⁸ (OVERFLOW!)
  
  But: a/gcd(a,b) = 2000000000/500000000 = 4
       4 * 1500000000 = 6000000000 ✓
```

**Code**:
```java
long lcm(int a, int b) {
    if (a == 0 || b == 0) return 0;
    return Math.abs((long) a / gcd(a, b) * b);
}
```

**Analysis**: Time O(log min(a,b)), Space O(1)

---

### Method 2: Prime Factorization

**Formula**: LCM = product of (max power of each prime)

**Example**: LCM(60, 90)
```
60 = 2² × 3¹ × 5¹
90 = 2¹ × 3² × 5¹

All primes: {2, 3, 5}

LCM = 2^max(2,1) × 3^max(1,2) × 5^max(1,1)
    = 2² × 3² × 5¹
    = 180
```

**Comparison**:
- GCD uses MIN powers (what they share)
- LCM uses MAX powers (where they meet)

**Analysis**: Time O(√a + √b), Space O(log a + log b)

---

### Method 3: Brute Force (Never Use)

**Algorithm**: Check multiples of max(a,b) until divisible by both

**Example**: LCM(4, 6)
```
Start at max=6
6:  6%4=2 ✗
12: 12%4=0 ✓, 12%6=0 ✓ → Answer
```

**Analysis**: Time O(a×b), Space O(1) - Extremely slow

## Part 4: Complete Properties

### GCD Properties (All 30+)

#### Identity Properties

**Property 1: GCD(a, a) = a**
```
Example: GCD(12, 12) = 12
Intuition: Largest divisor of a number with itself is the number
```

**Property 2: GCD(a, 1) = 1**
```
Example: GCD(100, 1) = 1
Intuition: 1 divides everything, but nothing larger than 1 divides 1
```

**Property 3: GCD(a, 0) = |a|**
```
Example: GCD(12, 0) = 12
Intuition: Every number divides 0 (0 = k×n for any k)
The largest divisor of a is a itself
```

#### Commutative & Associative

**Property 4: GCD(a, b) = GCD(b, a)** [Commutative]
```
Example: GCD(12, 18) = GCD(18, 12) = 6
```

**Property 5: GCD(a, GCD(b, c)) = GCD(GCD(a, b), c)** [Associative]
```
Example: GCD(12, GCD(18, 24)) = GCD(GCD(12, 18), 24)
       = GCD(12, 6) = GCD(6, 24)
       = 6
```

#### Distributive Properties

**Property 6: GCD(k×a, k×b) = k × GCD(a, b)**
```
Example: GCD(6×4, 6×9) = GCD(24, 54)
       = 6
       = 6 × GCD(4, 9)
       = 6 × 1

Application: Factor out common multiplier before computing
```

**Property 7: If d=GCD(a,b), then GCD(a/d, b/d) = 1**
```
Example: GCD(12, 18) = 6
         GCD(12/6, 18/6) = GCD(2, 3) = 1
         
Intuition: After dividing by GCD, numbers become coprime
```

#### Modular Properties

**Property 8: GCD(a, b) = GCD(b, a mod b)** [Euclidean]
```
Example: GCD(48, 18) = GCD(18, 12) = GCD(12, 6) = 6
This is why Euclidean algorithm works!
```

**Property 9: GCD(a, b) = GCD(a-b, b) if a > b** [Subtraction]
```
Example: GCD(18, 12) = GCD(6, 12) = GCD(6, 6) = 6
```

**Property 10: GCD(a, b) = GCD(a+b, b) = GCD(a, a+b)**
```
Example: GCD(12, 18) = GCD(30, 18) = GCD(12, 30) = 6

Proof: If d divides a and b, d divides a+b
```

#### Consecutive & Special Cases

**Property 11: GCD(n, n+1) = 1** [Consecutive]
```
Example: GCD(99, 100) = 1
         GCD(1000000, 1000001) = 1

Proof: Suppose d divides both n and n+1
       Then d divides (n+1) - n = 1
       So d = 1
```

**Property 12: If a|c and b|c, then LCM(a,b) | c**
```
Example: 4|12 and 6|12
         LCM(4,6)=12 divides 12
```

#### Prime Factor Properties

**Property 13: GCD using prime factorization**
```
If a = ∏ pᵢ^aᵢ and b = ∏ pᵢ^bᵢ
Then GCD(a,b) = ∏ pᵢ^min(aᵢ,bᵢ)

Example: 60 = 2² × 3¹ × 5¹
         90 = 2¹ × 3² × 5¹
         GCD = 2¹ × 3¹ × 5¹ = 30
```

**Property 14: GCD(a^n, b^n) = (GCD(a,b))^n**
```
Example: GCD(6, 9) = 3
         GCD(6², 9²) = GCD(36, 81) = 9 = 3²
         
         GCD(4, 6) = 2
         GCD(4³, 6³) = GCD(64, 216) = 8 = 2³
```

#### Bézout's Identity

**Property 15: For any a, b: ∃ integers x, y such that ax + by = GCD(a,b)**
```
Example: GCD(12, 18) = 6
         12×(-1) + 18×1 = -12 + 18 = 6 ✓
         12×5 + 18×(-3) = 60 - 54 = 6 ✓
         
This is found using Extended Euclidean Algorithm
```

#### Divisibility Properties

**Property 16: If d | GCD(a,b), then d | a and d | b**
```
Intuition: Any divisor of GCD divides both numbers
```

**Property 17: If d | a and d | b, then d | GCD(a,b)**
```
Proof: GCD is the largest such divisor
```

**Property 18: GCD(a,b) | a and GCD(a,b) | b**
```
This is the definition of GCD
```

#### Inequality Properties

**Property 19: GCD(a,b) ≤ min(a,b)**
```
Example: GCD(12, 18) = 6 ≤ 12
```

**Property 20: GCD(a,b) ≥ 1** (for positive integers)

#### Advanced Properties

**Property 21: GCD(a, b, c) = GCD(GCD(a, b), c)**
```
This extends GCD to multiple numbers
```

**Property 22: If GCD(a,b)=1 and a|bc, then a|c**
```
Example: GCD(3,10)=1, 3|30, so 3|3 ✓
```

**Property 23: If GCD(a,c)=1 and GCD(b,c)=1, then GCD(ab,c)=1**
```
Proof: If prime p divides ab and c, then p|a or p|b
       But GCD(a,c)=1 and GCD(b,c)=1 means no common primes
       Contradiction
```

**Property 24: GCD(a,bc) = GCD(a,b) × GCD(a/GCD(a,b), c)**
```
Complex but useful for optimization in some algorithms
```

### LCM Properties (All 20+)

#### Identity Properties

**Property 25: LCM(a, a) = a**
```
Example: LCM(12, 12) = 12
```

**Property 26: LCM(a, 1) = a**
```
Example: LCM(100, 1) = 100
```

**Property 27: LCM(a, 0) = 0**
```
Example: LCM(12, 0) = 0
Intuition: 0 is a multiple of everything
```

#### Commutative & Associative

**Property 28: LCM(a, b) = LCM(b, a)** [Commutative]
```
Example: LCM(12, 18) = LCM(18, 12) = 36
```

**Property 29: LCM(a, LCM(b,c)) = LCM(LCM(a,b), c)** [Associative]
```
Example: LCM(4, LCM(6,8)) = LCM(LCM(4,6), 8)
       = LCM(4, 24) = LCM(12, 8)
       = 24
```

#### Distributive Properties

**Property 30: LCM(k×a, k×b) = k × LCM(a,b)**
```
Example: LCM(6×4, 6×9) = LCM(24, 54)
       = 216
       = 6 × LCM(4, 9)
       = 6 × 36
```

#### Relationship with GCD

**Property 31: GCD(a,b) × LCM(a,b) = a × b** [THE KEY RELATIONSHIP]
```
Example: GCD(12,18) × LCM(12,18) = 6 × 36 = 216 = 12×18

WARNING: Only for 2 numbers!
GCD(4,6,8) × LCM(4,6,8) = 2 × 24 = 48 ≠ 4×6×8 = 192
```

**Property 32: LCM(a,b) = (a × b) / GCD(a,b)**
```
Derived from Property 31
```

#### Coprime Properties

**Property 33: If GCD(a,b)=1, then LCM(a,b) = a×b**
```
Example: GCD(8,15)=1
         LCM(8,15) = 8×15 = 120
         
Intuition: No shared factors to deduplicate
```

**Property 34: LCM(a,b) = a×b ⟺ GCD(a,b) = 1**
```
The reverse is also true
```

#### Divisibility Properties

**Property 35: a | LCM(a,b) and b | LCM(a,b)**
```
This is the definition of LCM
```

**Property 36: If a|m and b|m, then LCM(a,b) | m**
```
Example: 4|12 and 6|12
         LCM(4,6)=12 divides 12
```

#### Prime Factor Properties

**Property 37: LCM using prime factorization**
```
If a = ∏ pᵢ^aᵢ and b = ∏ pᵢ^bᵢ
Then LCM(a,b) = ∏ pᵢ^max(aᵢ,bᵢ)

Example: 60 = 2² × 3¹ × 5¹
         90 = 2¹ × 3² × 5¹
         LCM = 2² × 3² × 5¹ = 180
```

**Property 38: LCM(a^n, b^n) = (LCM(a,b))^n**
```
Example: LCM(4, 6) = 12
         LCM(4², 6²) = LCM(16, 36) = 144 = 12²
```

#### Inequality Properties

**Property 39: LCM(a,b) ≥ max(a,b)**
```
Example: LCM(12, 18) = 36 ≥ 18
```

**Property 40: max(a,b) ≤ LCM(a,b) ≤ a×b**
```
Equality at right when coprime
```

#### Combined Inequalities

**Property 41: GCD(a,b) ≤ min(a,b) ≤ max(a,b) ≤ LCM(a,b)**
```
Example: GCD(12,18)=6 ≤ 12 ≤ 18 ≤ 36=LCM(12,18)
```

#### Special Divisibility Cases

**Property 42: If a|b, then GCD(a,b)=a and LCM(a,b)=b**
```
Example: 12 divides 36
         GCD(12, 36) = 12
         LCM(12, 36) = 36
```

## Part 5: Coprime Numbers

### Definition

**Two numbers are coprime (relatively prime) if GCD(a, b) = 1**

**CRITICAL**: Coprime ≠ Prime!
- Coprime: numbers share no factors with EACH OTHER
- Prime: number has no factors except 1 and itself

### Examples

**Coprime pairs** (neither needs to be prime):
```
(8, 15):  GCD=1 ✓ Both composite!
(9, 16):  GCD=1 ✓ Both composite!
(7, 12):  GCD=1 ✓ One prime, one composite
(5, 7):   GCD=1 ✓ Both prime
```

**NOT coprime**:
```
(8, 12):  GCD=4 (share factor 2)
(15, 25): GCD=5 (share factor 5)
(6, 9):   GCD=3 (share factor 3)
```

### Key Properties of Coprime Numbers

**Property 1: Consecutive numbers always coprime**
```
GCD(n, n+1) = 1 for any n

Proof:
  Suppose d divides both n and n+1
  Then d divides (n+1) - n = 1
  So d = 1
  
Examples: GCD(99,100)=1, GCD(1000000,1000001)=1
```

**Property 2: Two primes always coprime (unless same)**
```
GCD(7, 11) = 1
GCD(13, 17) = 1
GCD(7, 7) = 7 (not coprime to itself)
```

**Property 3: If GCD(a,b)=1, then LCM(a,b) = a×b**
```
Example: GCD(8,15)=1
         LCM(8,15) = 8×15 = 120
```

**Property 4: Coprimality is NOT transitive**
```
GCD(4,9)=1 and GCD(4,15)=1
But GCD(9,15)=3 ✗
```

**Property 5: If GCD(a,b)=1 and GCD(a,c)=1, then GCD(a,bc)=1**
```
Proof: If prime p divides a and bc,
       then p|b or p|c
       But GCD(a,b)=1 and GCD(a,c)=1
       Contradiction
```

### Applications of Coprimality

**1. Fraction Simplification**: Fraction in simplest form ⟺ numerator and denominator coprime

**2. Modular Inverse**: a⁻¹ (mod m) exists ⟺ GCD(a,m)=1

**3. Cryptography**: RSA requires coprime numbers for key generation

**4. Hash Tables**: Probe step coprime to table size ensures full coverage

**5. Chinese Remainder Theorem**: Requires pairwise coprime moduli

## Part 6: Twin Primes & Related Concepts

### Twin Primes

**Definition**: Pairs of primes differing by exactly 2

**Examples**:
```
(3, 5), (5, 7), (11, 13), (17, 19), (29, 31),
(41, 43), (59, 61), (71, 73), (101, 103),
(137, 139), (149, 151), (179, 181), (191, 193),
(197, 199)
```

### Why Twin Primes Are Special

**Closest Possible**: Since all primes > 2 are odd, consecutive primes differ by at least 2

**The Twin Prime Conjecture**: There are infinitely many twin primes (UNPROVEN for 2000+ years!)

**Progress**:
- 2013: Zhang proved infinitely many primes with gap ≤ 70,000,000
- 2014: Polymath project reduced to gap ≤ 246
- Still not proven for gap = 2

### Pattern of Twin Primes

**Form**: (6k-1, 6k+1) for k ≥ 1

**Why?**
```
All primes > 3 are of form 6k±1 because:
  6k   divisible by 6
  6k+2 divisible by 2
  6k+3 divisible by 3
  6k+4 divisible by 2
  
Only 6k±1 can be prime

For twin primes:
  p = 6k-1 and p+2 = 6k+1

Examples:
  k=1: (5,7) = (6-1, 6+1)
  k=2: (11,13) = (12-1, 12+1)
  k=3: (17,19) = (18-1, 18+1)
```

### Why (7, 9) is NOT Twin Prime

```
7 is prime ✓
9 = 3² is composite ✗

BOTH must be prime!
```

```
(3,7), (7,11), (13,17), (19,23), (37,41)
```

```
(5,11), (7,13), (11,17), (13,19), (23,29)
Name from Latin "sex" = six
```

**Prime Triplets**:

```
Only one: (3, 5, 7)

Why? Among any 3 consecutive odd numbers,
one is divisible by 3.

Examples: (5,7,11), (7,11,13), (11,13,17)
```

## Part 7: Advanced Concepts

### Extended Euclidean Algorithm

**Purpose**: Find integers x, y such that **ax + by = GCD(a,b)**

This is **Bézout's Identity**.

**Why Important**:
- Foundation for modular arithmetic
- Computes modular multiplicative inverse
- Solves linear Diophantine equations
- Critical for RSA cryptography

**Detailed Example**: 35x + 49y = GCD(35, 49)

```
Forward (Euclidean):
  49 = 1×35 + 14  ...(1)
  35 = 2×14 + 7   ...(2)
  14 = 2×7 + 0    ...(3)
  
  GCD = 7

Backward:
  From (2): 7 = 35 - 2×14
  
  Substitute 14 from (1): 14 = 49 - 35
    7 = 35 - 2(49 - 35)
    7 = 35 - 2×49 + 2×35
    7 = 3×35 - 2×49
    
  So: x=3, y=-2

Verify: 35×3 + 49×(-2) = 105 - 98 = 7 ✓
```

### Modular Multiplicative Inverse

**Problem**: Find x such that **(a × x) ≡ 1 (mod m)**

**CRITICAL**: Inverse exists ⟺ GCD(a, m) = 1

**Why GCD Matters - Complete Proof**:

```
Suppose a⁻¹ exists:
  a × x ≡ 1 (mod m)
  
This means:
  a × x = m × k + 1 (for some k)
  
Rearranging:
  a × x - m × k = 1
  
By Bézout's identity, this has integer solutions
if and only if GCD(a,m) divides 1.

Since only 1 divides 1:
  GCD(a, m) must equal 1
  
Therefore a and m must be coprime!
```

**Example 1**: Find 3⁻¹ (mod 11)

```
Step 1: Check GCD(3, 11) = 1 ✓

Step 2: Use Extended GCD
  3x + 11y = 1
  Result: x=4, y=-1
  Verify: 3×4 + 11×(-1) = 12-11 = 1 ✓

Step 3: Inverse is x mod 11 = 4

Verify: 3×4 = 12 ≡ 1 (mod 11) ✓
```

**Example 2**: 6⁻¹ (mod 9) doesn't exist

```
GCD(6, 9) = 3 ≠ 1 ✗

Try all values:
  6×0=0 ≡ 0 (mod 9)
  6×1=6 ≡ 6 (mod 9)
  6×2=12 ≡ 3 (mod 9)
  6×3=18 ≡ 0 (mod 9)
  6×4=24 ≡ 6 (mod 9)
  
Pattern: {0, 3, 6} - never reaches 1!
```

**Code**:
```java
int modInverse(int a, int m) {
    int[] result = extendedGCD(a, m);
    if (result[0] != 1) {
        throw new ArithmeticException(
            "Inverse doesn't exist: GCD(" + a + "," + m + ") = " + result[0]
        );
    }
    return ((result[1] % m) + m) % m;
}
```

### Applications

**1. Solving Linear Congruences**:

```java
    int[] prefix = new int[n];
    int[] suffix = new int[n];
    
    prefix[0] = arr[0];
    for (int i = 1; i < n; i++) {
        prefix[i] = gcd(prefix[i-1], arr[i]);
    }

    for (int i = n-2; i >= 0; i--) {

    for (int i = 1; i < n-1; i++) {

    }
    
    return maxGCD;
}
```

## Part 9: Complete Code Library

```java
public class NumberTheoryLibrary {
    
    // ============ GCD ALGORITHMS ============
    
    // Euclidean (iterative) - DEFAULT
    static int gcd(int a, int b) {
        while (b != 0) {
            int temp = b;
            b = a % b;
            a = temp;
        }
        return a;
    }
    
    // Euclidean (recursive)
    static int gcdRec(int a, int b) {
        return b == 0 ? a : gcdRec(b, a % b);
    }
    
    // Binary GCD - for large numbers
    static int gcdBinary(int a, int b) {
        if (a == 0) return b;
        if (b == 0) return a;
        
        int shift = 0;
        while (((a | b) & 1) == 0) {
            a >>= 1; b >>= 1; shift++;
        }
        while ((a & 1) == 0) a >>= 1;
        while (b != 0) {
            while ((b & 1) == 0) b >>= 1;
            if (a > b) { int t = a; a = b; b = t; }
            b -= a;
        }
        return a << shift;
    }
    
    // Extended GCD
    static int[] extGCD(int a, int b) {
        if (b == 0) return new int[]{a, 1, 0};
        int[] r = extGCD(b, a % b);
        return new int[]{r[0], r[2], r[1] - (a/b) * r[2]};
    }
    
    // ============ LCM ============
    
    static long lcm(int a, int b) {
        if (a == 0 || b == 0) return 0;
        return Math.abs((long) a / gcd(a, b) * b);
    }
    
    // ============ ARRAY OPERATIONS ============
    
    static int gcdArray(int[] arr) {
        int g = arr[0];
        for (int i = 1; i < arr.length; i++) {
            g = gcd(g, arr[i]);
            if (g == 1) break;
        }
        return g;
    }
    
    static long lcmArray(int[] arr) {
        long l = arr[0];
        for (int i = 1; i < arr.length; i++) {
            l = lcm((int)l, arr[i]);
        }
        return l;
    }
    
    // ============ COPRIMALITY ============
    
    static boolean coprime(int a, int b) {
        return gcd(a, b) == 1;
    }
    
    static int eulerPhi(int n) {
        int result = n;
        for (int p = 2; p * p <= n; p++) {
            if (n % p == 0) {
                while (n % p == 0) n /= p;
                result -= result / p;
            }
        }
        if (n > 1) result -= result / n;
        return result;
    }
    
    // ============ MODULAR ARITHMETIC ============
    
    static int modInverse(int a, int m) {
        int[] r = extGCD(a, m);
        if (r[0] != 1) return -1;
        return ((r[1] % m) + m) % m;
    }
    
    static int modDivide(int a, int b, int m) {
        int bInv = modInverse(b, m);
        if (bInv == -1) return -1;
        return (int)(((long)a * bInv) % m);
    }
    
    static int solveCongruence(int a, int b, int m) {
        int g = gcd(a, m);
        if (b % g != 0) return -1;
        return modDivide(b/g, a/g, m/g);
    }
    
    // ============ UTILITIES ============
    
    static int[] simplify(int num, int den) {
        int g = gcd(num, den);
        return new int[]{num/g, den/g};
    }
    
    static boolean isPrime(int n) {
        if (n < 2) return false;
        if (n == 2) return true;
        if (n % 2 == 0) return false;
        for (int i = 3; i * i <= n; i += 2) {
            if (n % i == 0) return false;
        }
        return true;
    }
    
    static Map<Integer, Integer> primeFactors(int n) {
        Map<Integer, Integer> f = new HashMap<>();
        while (n % 2 == 0) {
            f.put(2, f.getOrDefault(2, 0) + 1);
            n /= 2;
        }
        for (int i = 3; i * i <= n; i += 2) {
            while (n % i == 0) {
                f.put(i, f.getOrDefault(i, 0) + 1);
                n /= i;
            }
        }
        if (n > 1) f.put(n, 1);
        return f;
    }
}
```

## Part 10: Quick Reference Tables

### Algorithm Comparison

| Algorithm | Time | Space | When to Use |
|-----------|------|-------|-------------|
| Euclidean GCD | O(log n) | O(1) | **Default choice** |
| Binary GCD | O(log n) | O(1) | Large numbers (>10¹⁸) |
| Prime Factor | O(√n) | O(log n) | Multiple operations |
| Brute Force | O(n) | O(1) | Never |

### Problem-Technique Mapping

| Keywords | Technique | What to Compute | Example |
|----------|-----------|-----------------|---------|
| "simplify", "reduce" | GCD division | num/gcd, den/gcd | 48/72 → 2/3 |
| "meet", "sync" | LCM | lcm(periods) | Bus 15min, 20min → 60min |
| "largest tile" | GCD | gcd(dimensions) | 48×108 → 12cm |
| "distribute" | GCD | gcd(items) | 36,48 → 12 baskets |
| "ax≡b (mod m)" | Mod inverse | Check gcd, solve | 5x≡3(mod 7) → x=2 |
| "coprime" | GCD=1 check | gcd(a,b)==1 | (8,15) coprime? Yes |
| "array GCD" | Iterative | gcd of all | [12,18,24] → 6 |

### Property Quick Reference

| Property | GCD | LCM |
|----------|-----|-----|
| Identity with self | GCD(a,a) = a | LCM(a,a) = a |
| Identity with 1 | GCD(a,1) = 1 | LCM(a,1) = a |
| Identity with 0 | GCD(a,0) = a | LCM(a,0) = 0 |
| Commutative | ✓ | ✓ |
| Associative | ✓ | ✓ |
| Distributive (×k) | k×GCD(a,b) | k×LCM(a,b) |
| With powers | (GCD)^n | (LCM)^n |
| Consecutive | GCD(n,n+1)=1 | - |
| Coprime | GCD=1 → LCM=a×b | - |
| Product | GCD×LCM = a×b | (2 numbers only!) |

### Common Mistakes

| ❌ Wrong | ✅ Correct | Why |
|---------|-----------|-----|
| `(a*b)/gcd` | `a/gcd*b` | Overflow |
| GCD×LCM=abc | Only for 2 nums | Formula breaks |
| `modInv(a,m)` | Check gcd first | May not exist |
| Brute force | Euclidean | Too slow |
| Ignore a=0,b=0 | Handle edge cases | Crashes |

### Complexity Cheat Sheet

```
gcd(a, b)              → O(log min(a,b))
lcm(a, b)              → O(log min(a,b))
gcdArray(n elements)   → O(n log max_element)
lcmArray(n elements)   → O(n log max_element)
modInverse(a, m)       → O(log min(a,m))
primeFactors(n)        → O(√n)
eulerPhi(n)            → O(√n)
```
