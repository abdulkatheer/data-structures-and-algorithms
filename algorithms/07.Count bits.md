In Java, there are **three common ways** to count the number of set bits (`1`s) in an integer. I’ll
list them from **most optimal / idiomatic** to **educational**.

---

## ✅ 1. Built-in (Best & Fastest)

```java
int count = Integer.bitCount(n);
```

### Why this is best

* Uses **hardware-level instructions** (POPCNT when available)
* Time: **O(1)**
* Clean and interview-acceptable

👉 Always prefer this in production unless asked otherwise.

---

## ✅ 2. Brian Kernighan’s Algorithm (Classic)

```java
int count = 0;
while(n !=0){
n =n &(n -1);
count++;
    }
```

### Why it works

* `n & (n - 1)` **removes the lowest set bit**
* Loop runs only **number of set bits** times

### Complexity

* Time: **O(number of set bits)**
* Space: **O(1)**

💡 This is the **most commonly expected manual solution** in interviews.

---

## ✅ 3. Bit-by-Bit (Simple but Slower)

```java
int count = 0;
while(n !=0){
count +=(n &1);
n >>=1;
    }
```

### Complexity

* Time: **O(number of bits)** → 32 iterations for `int`
* Space: **O(1)**

⚠️ Less optimal but easiest to understand.

---

## ⚠️ Important Java Detail (Negative Numbers)

Java uses **two’s complement**, so right shift matters:

* Use `>>>` (unsigned shift) if you want predictable behavior:

```java
while(n !=0){
count +=(n &1);
n >>>=1;
    }
```

But `Integer.bitCount()` already handles this correctly.

---

## 🔍 Example

```java
int n = 13; // binary: 1101
System.out.

println(Integer.bitCount(n)); // 3
```
