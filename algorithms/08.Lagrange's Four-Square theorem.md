# 🔢 Lagrange’s Four-Square Theorem

> **Every non-negative integer can be written as the sum of four perfect squares.**

Formally:
[
\forall n \ge 0,\quad n = a^2 + b^2 + c^2 + d^2
]
for some integers (a,b,c,d).

✔ Proven by **Joseph-Louis Lagrange (1770)**
✔ This is a **guarantee**, not an algorithm.

---

## 1️⃣ What the theorem REALLY means

It tells you:

* You will **never need more than 4 squares**
* The answer to LeetCode 279 is always in `{1,2,3,4}`

But:
❌ It does **not** tell you *which* squares
❌ It does **not** minimize automatically

That’s why DP / BFS still exists.

---

## 2️⃣ Why this matters for LeetCode 279

Problem:

> Find the **minimum** number of perfect squares that sum to `n`.

Because of Lagrange:

| Minimum | Meaning                        |
|---------|--------------------------------|
| `1`     | `n` itself is a perfect square |
| `2`     | sum of two squares             |
| `3`     | sum of three squares           |
| `4`     | otherwise (guaranteed)         |

So the search space collapses from **DP(n)** → **constant checks**

---

## 3️⃣ Case 1: Answer = 1 (Perfect Square)

Check:
[
n = k^2
]

```java
int r = (int) Math.sqrt(n);
if(r *r ==n)return 1;
```

---

## 4️⃣ Case 2: Answer = 2 (Sum of Two Squares)

We test:
[
n = a^2 + b^2
]

Algorithm:

* Loop `a²`
* Check if `n - a²` is a square

```java
for(int i = 1;
i *i <=n;i++){
int rem = n - i * i;
int r = (int) Math.sqrt(rem);
    if(r *r ==rem)return 2;
    }
```

Time: `O(√n)`

---

## 5️⃣ Case 3 & 4: Legendre’s Three-Square Theorem ⚠️

Here is the **real magic**.

### 🔥 Legendre’s Three-Square Theorem

> A number **cannot** be written as the sum of three squares **iff**
> [
> n = 4^a(8b + 7)
> ]

If this form holds → answer is **4**
Otherwise → answer is **3**

---

## 6️⃣ Why this form blocks 3 squares

Squares modulo 8:

```
0² ≡ 0
1² ≡ 1
2² ≡ 4
3² ≡ 1
4² ≡ 0
```

Possible sums of three squares mod 8:

```
0,1,2,3,4,5,6
```

🚫 **7 never appears**

Multiplying by powers of 4 preserves the impossibility.

---

## 7️⃣ How to check the forbidden form

```java
while(n %4==0){
n /=4;
    }

    if(n %8==7)return 4;
```

---

## 8️⃣ Final Lagrange-Based Solution (Optimal)

```java
class Solution {

  public int numSquares(int n) {
    // Case 1
    int r = (int) Math.sqrt(n);
    if (r * r == n)
      return 1;

    // Case 2
    for (int i = 1; i * i <= n; i++) {
      int rem = n - i * i;
      int rr = (int) Math.sqrt(rem);
      if (rr * rr == rem)
        return 2;
    }

    // Case 3 / 4 (Legendre)
    int temp = n;
    while (temp % 4 == 0)
      temp /= 4;
    if (temp % 8 == 7)
      return 4;

    return 3;
  }
}
```

## 9️⃣ Why this is mathematically complete

* Lagrange ⇒ answer ≤ 4
* Perfect square ⇒ 1
* Two-square test ⇒ 2
* Legendre filter ⇒ 3 or 4

✔ Time: `O(√n)`
✔ Space: `O(1)`
✔ Faster than DP for large `n`

## 🔑 Core Difference (One-line intuition)

* **Lagrange’s 4-Square Theorem** → gives an **upper bound**
* **Legendre’s 3-Square Theorem** → tells you **when 3 is impossible**

They **complement**, not replace, each other.

---

## 1️⃣ Lagrange’s Four-Square Theorem

### Statement

> Every non-negative integer can be written as the sum of **four** squares.

[
n = a^2 + b^2 + c^2 + d^2
]

### What it gives you

* Guarantees **answer ≤ 4**
* Shrinks the problem’s output space to `{1,2,3,4}`

### What it does NOT give

* Does ❌ NOT tell you if the answer is 1, 2, or 3
* Does ❌ NOT help decide *minimum*

### In LeetCode 279

Lagrange tells you:

> “If nothing else works, return 4.”

---

## 2️⃣ Legendre’s Three-Square Theorem

### Statement

A number **cannot** be written as the sum of **three squares** **iff**:
[
n = 4^a(8b + 7)
]

### What it gives you

* A **precise filter** for when 3 squares are impossible
* Lets you decide **3 vs 4** in O(1)

### Why it’s powerful

Instead of searching combinations, you **prove impossibility**.

---

## 3️⃣ How they work together (Decision Flow)

```
Is n a perfect square?
    → yes → 1

Can n be written as sum of two squares?
    → yes → 2

Is n of form 4^a(8b+7)?
    → yes → 4

Otherwise
    → 3
```

👉 This logic is **impossible** using Lagrange alone.

---

## 4️⃣ Example Walkthrough

### Example 1: n = 12

```
12 ≠ perfect square
12 = 4 + 4 + 4 → 3 squares
12 mod pattern ≠ 4^a(8b+7)
```

✅ Answer = 3

---

### Example 2: n = 7

```
7 ≠ perfect square
7 ≠ sum of 2 squares
7 = 4^0(8×0 + 7)
```

❌ 3 squares impossible
✔ Lagrange guarantees 4
✅ Answer = 4

---

### Example 3: n = 28

```
28 = 4 × 7
7 = 8×0 + 7
→ forbidden form
```

✅ Answer = 4
