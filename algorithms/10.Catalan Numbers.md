## 1. Definition & Formula

**The nth Catalan number** C_n counts certain types of combinatorial structures of size n.

### Core Formulas

1. **Recursive Definition:**
    - C_0 = 1
    - C_n = Σ(i=0 to n-1) C_i × C_(n-1-i)

2. **Closed Form (Binomial Coefficient):**
    - C_n = (1/(n+1)) × C(2n, n) = (2n)! / ((n+1)! × n!)

3. **Alternative Forms:**
    - C_n = C(2n, n) - C(2n, n+1)
    - C_n = C(2n, n) / (n+1)

### First Few Values

- C_0 = 1, C_1 = 1, C_2 = 2, C_3 = 5, C_4 = 14, C_5 = 42, C_6 = 132, C_7 = 429, C_8 = 1430

## 2. Mathematical Intuition

### Why This Formula Works

**Fundamental Insight:** Catalan numbers count structures that can be recursively decomposed based
on "where the first split occurs."

**Example - Balanced Parentheses:**
For n pairs, consider where the *first opening parenthesis closes*:

- If it closes at position 2k (forming k pairs inside), we have:
    - C_(k-1) ways to fill the inside (k-1 pairs)
    - C_(n-k) ways to fill the rest (n-k pairs)

Summing over all possible k: C_n = Σ C_(k-1) × C_(n-k)

**Path Counting Insight (Ballot Problem):**

- Valid paths from (0,0) to (n,n) staying below y=x
- Total paths: C(2n, n)
- Invalid paths (crossing y=x): those that touch (n-1, n+1), which equal C(2n, n+1) by reflection
  principle
- Valid paths: C(2n, n) - C(2n, n+1) = C_n

## 3. Classic Problems Counted by Catalan Numbers

### A. Balanced Parentheses (Dyck Paths)

**Problem:** Number of ways to arrange n pairs of balanced parentheses

**Example (n=3):** ((())), (()()), (())(), ()(()), ()()()

**Why Catalan:** Each valid sequence corresponds to a path that never goes below the x-axis
when '(' = +1, ')' = -1

---

### B. Binary Search Trees

**Problem:** Number of structurally unique BSTs with n distinct keys

**Example (n=3):** 5 different tree structures

**Why Catalan:** Choose root k, then C_(k-1) ways for left subtree × C_(n-k) ways for right subtree

**Recurrence:**

```
T(n) = Σ(k=1 to n) T(k-1) × T(n-k)
```

---

### C. Valid Path Through Grid (Ballot Problem)

**Problem:** Paths from (0,0) to (n,n) that never cross diagonal y=x (stay at or below)

**Constraint:** At any point, #ups ≤ #rights

**Why Catalan:** Monotonic lattice paths with order constraint

---

### D. Polygon Triangulation

**Problem:** Number of ways to triangulate a convex (n+2)-gon using n non-crossing diagonals

**Example (n=2, pentagon):** 5 ways to triangulate

**Why Catalan:** Choose one edge as base, recursively triangulate the two resulting polygons

---

### E. Mountain Ranges

**Problem:** Number of ways to draw n upstrokes (/) and n downstrokes (\) forming a mountain range (
never going below ground)

**Example (n=3):** /\/\/\, /\/\\ /, /\\ /\/\, etc.

**Why Catalan:** Equivalent to balanced parentheses with / = '(' and \ = ')'

---

### F. Full Binary Trees

**Problem:** Number of full binary trees with n+1 leaves (2n+1 total nodes)

**Why Catalan:** Each internal node has exactly 2 children; choose left/right subtree sizes

---

### G. Non-Crossing Handshakes

**Problem:** 2n people in a circle, number of ways they can shake hands pairwise without crossing
arms

**Why Catalan:** Person 1 shakes with person 2k; creates two independent subproblems of size k-1 and
n-k

---

### H. Stack-Sortable Permutations

**Problem:** Number of permutations of {1,2,...,n} that can be sorted using a single stack

**Pattern:** Permutations avoiding the pattern 231

**Why Catalan:** Valid permutations correspond to valid sequences of push/pop operations

## 4. How to Identify Catalan Problems

### Key Recognition Patterns

#### Pattern 1: Recursive Binary Decomposition

**Signals:**

- "Choose a split point, solve two independent subproblems"
- Left/right, inside/outside dichotomy
- Tree-like recursive structure

**Examples:** BSTs, triangulation, expression trees

---

#### Pattern 2: Balanced Sequences

**Signals:**

- Pairs of opening/closing symbols
- Never go negative (prefix sum constraint)
- "Valid" sequences with matching pairs

**Examples:** Parentheses, mountain ranges, Dyck paths

---

#### Pattern 3: Non-Crossing Structures

**Signals:**

- Planar arrangements (no crossings)
- Circular configurations with pairing
- Geometric constraints

**Examples:** Handshakes, chord diagrams, polygon diagonals

---

#### Pattern 4: Monotonic Paths with Constraint

**Signals:**

- Grid paths with order restriction
- "Never exceed" or "stay below diagonal" conditions
- Ballot/voting problems

**Examples:** Grid paths, ballot sequences

---

#### Pattern 5: Structural Counting with Symmetry

**Signals:**

- Count structurally unique objects
- Recursive structure with n elements
- Combinatorial formula matches C_n pattern

**Examples:** Binary trees, expression parenthesization

---

### Decision Tree: Is This a Catalan Problem?

```
1. Does it involve n pairs or 2n objects?
   ├─ Yes → Continue
   └─ No → Probably not Catalan

2. Is there a recursive binary split?
   ├─ Yes (BST-style, triangulation) → Likely Catalan
   └─ Continue

3. Are there balanced/matching constraints?
   ├─ Yes (parentheses, +/- balance) → Likely Catalan
   └─ Continue

4. Are there non-crossing requirements?
   ├─ Yes (planar, circular) → Likely Catalan
   └─ Continue

5. Does the recurrence match: C_n = Σ C_i × C_(n-1-i)?
   ├─ Yes → Definitely Catalan
   └─ No → Check for variant or different pattern
```

## 5. Implementation Techniques

### A. Dynamic Programming (Most Common)

```python
def catalan_dp(n):
    """
    Compute nth Catalan number using DP
    Time: O(n²), Space: O(n)
    """
    if n <= 1:
        return 1
    
    dp = [0] * (n + 1)
    dp[0] = dp[1] = 1
    
    # dp[i] = sum of dp[j] * dp[i-1-j] for j in [0, i-1]
    for i in range(2, n + 1):
        for j in range(i):
            dp[i] += dp[j] * dp[i - 1 - j]
    
    return dp[n]
```

**When to Use:** When n is moderate (≤5000) and you need exact values

---

### B. Binomial Coefficient Formula

```python
def catalan_binomial(n):
    """
    Compute using C_n = C(2n, n) / (n+1)
    Time: O(n), Space: O(1)
    """
    if n <= 1:
        return 1
    
    # Calculate C(2n, n)
    result = 1
    for i in range(n):
        result = result * (2 * n - i) // (i + 1)
    
    # Divide by (n+1)
    return result // (n + 1)
```

**When to Use:** When you need faster computation and have good integer division

---

### C. Modular Arithmetic (For Large Results)

```python
def catalan_mod(n, MOD):
    """
    Compute nth Catalan number modulo MOD
    Requires MOD to be prime for modular inverse
    Time: O(n), Space: O(n)
    """
    # Precompute factorials and inverse factorials
    fact = [1] * (2 * n + 1)
    for i in range(1, 2 * n + 1):
        fact[i] = fact[i-1] * i % MOD
    
    # Compute modular inverse of (n+1)! * n! using Fermat's little theorem
    inv_denominator = pow(fact[n+1] * fact[n], MOD - 2, MOD)
    
    # C_n = (2n)! / ((n+1)! * n!)
    return fact[2*n] * inv_denominator % MOD
```

**When to Use:** Competitive programming with large n and modulo requirement

---

### D. Memoization (Top-Down)

```python
from functools import lru_cache

@lru_cache(maxsize=None)
def catalan_memo(n):
    """
    Top-down recursive with memoization
    Time: O(n²), Space: O(n²) due to recursion
    """
    if n <= 1:
        return 1
    
    result = 0
    for i in range(n):
        result += catalan_memo(i) * catalan_memo(n - 1 - i)
    
    return result
```

**When to Use:** When problem naturally fits recursive formulation

## 7. Detailed Problem Walkthroughs

### Problem 96: Unique Binary Search Trees

**Problem Statement:** Given n, return the number of structurally unique BSTs with nodes 1 to n.

**Solution:**

```python
def numTrees(n: int) -> int:
    """
    For each number i as root:
    - Left subtree: nodes [1, i-1] → i-1 nodes → dp[i-1] trees
    - Right subtree: nodes [i+1, n] → n-i nodes → dp[n-i] trees
    - Total for root i: dp[i-1] * dp[n-i]
    """
    dp = [0] * (n + 1)
    dp[0] = dp[1] = 1
    
    for nodes in range(2, n + 1):
        for root in range(1, nodes + 1):
            left_count = root - 1
            right_count = nodes - root
            dp[nodes] += dp[left_count] * dp[right_count]
    
    return dp[n]
```

**Time:** O(n²), **Space:** O(n)

### Problem 22: Generate Parentheses

**Problem Statement:** Generate all valid n-pair parentheses combinations.

**Approach:** Not just counting (which would be C_n), but generating all valid sequences.

**Solution:**

```python
def generateParenthesis(n: int) -> list[str]:
    """
    Backtracking with balance constraint.
    At each step: can add '(' if open < n, can add ')' if close < open
    """
    result = []
    
    def backtrack(current, open_count, close_count):
        if len(current) == 2 * n:
            result.append(current)
            return
        
        if open_count < n:
            backtrack(current + '(', open_count + 1, close_count)
        
        if close_count < open_count:
            backtrack(current + ')', open_count, close_count + 1)
    
    backtrack('', 0, 0)
    return result
```

**Count:** len(result) = C_n

### Problem 1259: Handshakes That Don't Cross

**Problem Statement:** 2n people in circle, count non-crossing handshake pairings.

**Analysis:**

- Person 0 shakes with person k (where k is odd for non-crossing)
- Creates two groups: [1, k-1] and [k+1, 2n-1]
- Subproblems have (k-1)/2 and (2n-k-1)/2 pairs

**Solution:**

```python
def numberOfWays(num_people: int) -> int:
    """
    Direct Catalan number computation
    num_people = 2n, so we need C_n
    """
    MOD = 10**9 + 7
    n = num_people // 2
    
    # Compute C_n using DP
    dp = [0] * (n + 1)
    dp[0] = 1
    
    for i in range(1, n + 1):
        for j in range(i):
            dp[i] = (dp[i] + dp[j] * dp[i - 1 - j]) % MOD
    
    return dp[n]
```

**Alternative (Binomial):**

```python
def numberOfWays(num_people: int) -> int:
    MOD = 10**9 + 7
    n = num_people // 2
    
    # Compute factorials
    fact = [1] * (2*n + 1)
    for i in range(1, 2*n + 1):
        fact[i] = fact[i-1] * i % MOD
    
    # Modular inverse
    inv = pow(fact[n+1] * fact[n], MOD - 2, MOD)
    
    return fact[2*n] * inv % MOD
```

## 8. Advanced Variants & Extensions

### Generalized Catalan Numbers

**Formula:** C(m,n) = ((m-n+1)/(m+1)) × C(m+n, n)

**Application:** Paths from (0,0) to (m,n) that don't cross y=x

---

### Super Catalan Numbers

**Formula:** S(n) = ((3n)! × 2) / ((n+1)! × (2n+1)!)

**Counts:** Certain planar trees and diagonal-avoiding lattice paths

---

### Fuss-Catalan Numbers

**Formula:** C_n^(p) = (1/(pn+1)) × C(pn+n, n)

**Application:** Generalization where p-fold operations replace binary splits

## 9. Common Mistakes & Edge Cases

### Mistake 1: Off-by-One Errors

- **Tree nodes vs pairs:** n nodes gives C_(n-1) trees (not C_n)
- **Polygon vertices:** (n+2)-gon gives C_n triangulations

### Mistake 2: Modulo Arithmetic

- Must use modular inverse for division
- Fermat's little theorem: a^(-1) ≡ a^(p-2) (mod p) when p is prime

### Mistake 3: Integer Overflow

- Use `long long` in C++ or Python's arbitrary precision
- Apply modulo at each step, not just final result

### Edge Cases

- n=0: Always returns 1 (empty structure)
- n=1: Returns 1 (single element)
- Large n: Use binomial or modular approach, not naive recursion

## 11. Interview Tips

### When Asked a Counting Problem

1. **Check for n pairs or 2n objects** - immediate Catalan signal
2. **Look for recursive binary structure** - "choose a split, solve two sides"
3. **Identify constraints** - balanced, non-crossing, monotonic
4. **State the pattern clearly:** "This is a Catalan number problem because..."

### Complexity Discussion

- Naive recursion: O(C_n) ≈ O(4^n / n^(3/2)) - exponential
- DP: O(n²) time, O(n) space - standard approach
- Binomial: O(n) time, O(1) space - optimal for just counting

### Common Follow-ups

- "How would you generate all structures?" → Backtracking with count validation
- "What if we need modulo?" → Modular inverse technique
- "Can you prove the formula?" → Ballot problem or recursive decomposition
