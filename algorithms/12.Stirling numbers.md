# Part 1: Stirling Numbers of the Second Kind

## **Core Definition**

**S(n,k)** = The number of ways to partition a set of **n distinct labeled elements** into exactly *
*k non-empty unlabeled subsets**.

### **Key Terms Explained**

- **Partition:** Divide all elements into groups
- **Distinct/Labeled:** Elements are different (like {1,2,3}, not just "3 items")
- **Non-empty:** Every subset must contain at least one element
- **Unlabeled subsets:** The subsets themselves have no names/order
    - {{1,2},{3}} is the same as {{3},{1,2}}

---

## **Understanding Through Examples**

### **S(3,2) = 3 - Partition {1,2,3} into 2 subsets**

**All possible partitions:**

1. **{1,2} | {3}**
    - Subset 1: {1,2}
    - Subset 2: {3}

2. **{1,3} | {2}**
    - Subset 1: {1,3}
    - Subset 2: {2}

3. **{2,3} | {1}**
    - Subset 1: {2,3}
    - Subset 2: {1}

**Why not more?**

- We don't count {1}|{2,3} separately from {2,3}|{1} because subsets are **unlabeled**
- Order doesn't matter: the partition {{1,2},{3}} = {{3},{1,2}}

**Answer: S(3,2) = 3** ✓

---

### **S(4,2) = 7 - Partition {1,2,3,4} into 2 subsets**

**Strategy:** One subset has 1 element, the other has 3, OR both have 2 elements.

#### **Type A: One singleton, one triple (size: 1+3)**

1. {1} | {2,3,4}
2. {2} | {1,3,4}
3. {3} | {1,2,4}
4. {4} | {1,2,3}

**Count:** 4 ways (choose which element is alone)

#### **Type B: Two pairs (size: 2+2)**

5. {1,2} | {3,4}
6. {1,3} | {2,4}
7. {1,4} | {2,3}

**Count:** 3 ways

**Why only 3?** We must avoid double-counting:

- {1,2}|{3,4} is the same as {3,4}|{1,2}
- Total ways to split into pairs: C(4,2)/2 = 6/2 = 3

**Answer: S(4,2) = 7** ✓

---

### **S(4,3) = 6 - Partition {1,2,3,4} into 3 subsets**

With 4 elements in 3 subsets, we must have sizes: 2+1+1

**Choose which 2 elements go together:**

1. {1,2} | {3} | {4}
2. {1,3} | {2} | {4}
3. {1,4} | {2} | {3}
4. {2,3} | {1} | {4}
5. {2,4} | {1} | {3}
6. {3,4} | {1} | {2}

**Count:** C(4,2) = 6 ways

**Answer: S(4,3) = 6** ✓

---

### **S(5,3) = 25 - Partition {1,2,3,4,5} into 3 subsets**

Possible size distributions:

- **Type A:** 3+1+1 (one triple, two singletons)
- **Type B:** 2+2+1 (two pairs, one singleton)

#### **Type A: 3+1+1**

- Choose 3 elements for the triple: C(5,3) = 10
- Remaining 2 are singletons
- Count: **10 ways**

#### **Type B: 2+2+1**

- Choose 1 element to be alone: C(5,1) = 5
- Split remaining 4 into 2 pairs: C(4,2)/2 = 3
- Count: 5 × 3 = **15 ways**

**Answer: S(5,3) = 10 + 15 = 25** ✓

---

## **The Recurrence Relation**

```
S(n,k) = k·S(n-1,k) + S(n-1,k-1)
```

### **Intuition: Where Does Element n Go?**

When partitioning {1,2,...,n} into k subsets, focus on element **n**:

**Case 1: Element n joins an existing subset**

- First partition {1,2,...,n-1} into k subsets: **S(n-1,k)** ways
- Element n can join any of these k subsets: **k choices**
- Total: **k · S(n-1,k)**

**Case 2: Element n forms its own subset**

- Partition {1,2,...,n-1} into k-1 subsets: **S(n-1,k-1)** ways
- Element n becomes the k-th subset: **{n}**
- Total: **S(n-1,k-1)**

**These are mutually exclusive and exhaustive**, so:

```
S(n,k) = k·S(n-1,k) + S(n-1,k-1)
```

---

### **Visual Proof with S(4,2) = 7**

```
S(4,2) = 2·S(3,2) + S(3,1)
       = 2·3 + 1
       = 7 ✓
```

#### **Case 1: Element 4 joins an existing subset (2·S(3,2) = 6 partitions)**

Start with S(3,2) = 3 partitions of {1,2,3}:

- {1,2}|{3}
- {1,3}|{2}
- {2,3}|{1}

For each, add 4 to either subset (2 choices):

From **{1,2}|{3}**:

1. {1,2,4}|{3} ← add 4 to first subset
2. {1,2}|{3,4} ← add 4 to second subset

From **{1,3}|{2}**:

3. {1,3,4}|{2}
4. {1,3}|{2,4}

From **{2,3}|{1}**:

5. {2,3,4}|{1}
6. {2,3}|{1,4}

**Count: 6 partitions**

#### **Case 2: Element 4 forms its own subset (S(3,1) = 1 partition)**

Start with S(3,1) = 1 partition of {1,2,3}:

- {1,2,3}

Add {4} as new subset:

7. {1,2,3}|{4}

**Count: 1 partition**

**Total: 6 + 1 = 7** ✓

## **Base Cases**

```
S(0,0) = 1    Empty set into 0 subsets (vacuously true)
S(n,0) = 0    Can't partition n>0 elements into 0 subsets
S(0,k) = 0    Can't partition 0 elements into k>0 non-empty subsets
S(n,n) = 1    Each element in its own subset: {1}|{2}|...|{n}
S(n,1) = 1    All elements in one subset: {1,2,...,n}
S(n,k) = 0    Impossible if k > n (can't have more subsets than elements)
```

### **Special Formulas**

```
S(n,2) = 2^(n-1) - 1

S(n,n-1) = C(n,2) = n(n-1)/2
```

**Proof of S(n,n-1):**

- With n-1 subsets from n elements, exactly one subset has 2 elements, rest are singletons
- Choose which 2 elements pair up: C(n,2) ways

---

## **Complete S(n,k) Table**

```
n\k   0   1    2    3    4    5    6    7
0     1
1     0   1
2     0   1    1
3     0   1    3    1
4     0   1    7    6    1
5     0   1   15   25   10    1
6     0   1   31   90   65   15    1
7     0   1   63  301  350  140   21    1
```

**Pattern observations:**

- Row sums: S(n,0) + S(n,1) + ... + S(n,n) = **Bell number B(n)**
- Symmetric growth around k ≈ n/2
- S(n,2) doubles roughly: 1,3,7,15,31,63...

---

## **Closed-Form Formula (Inclusion-Exclusion)**

```
S(n,k) = (1/k!) · Σ(i=0 to k) (-1)^(k-i) · C(k,i) · i^n
```

### **Derivation Sketch**

**Problem:** Count surjective (onto) functions from n-set to k-set, then unlabel.

1. **Total functions** from n elements to k labeled boxes: k^n
2. **Subtract** functions missing at least one box (inclusion-exclusion)
3. **Divide by k!** to remove labeling of boxes

**Detailed steps:**

Let boxes be labeled 1,2,...,k.

- Functions using all k boxes = surjective functions
- Use inclusion-exclusion on "bad" functions (missing ≥1 box)

|Surjective functions| = Σ(i=0 to k) (-1)^i · C(k,i) · (k-i)^n

Reindex with j = k-i:
= Σ(j=0 to k) (-1)^(k-j) · C(k,j) · j^n

Since boxes are labeled, divide by k! for unlabeled partitions:

**S(n,k) = (1/k!) · Σ(j=0 to k) (-1)^(k-j) · C(k,j) · j^n**

---

### **Example: S(4,2) using formula**

```
S(4,2) = (1/2!) · [(-1)^(2-0)·C(2,0)·0^4 + (-1)^(2-1)·C(2,1)·1^4 + (-1)^(2-2)·C(2,2)·2^4]
       = (1/2) · [1·1·0 + (-1)·2·1 + 1·1·16]
       = (1/2) · [0 - 2 + 16]
       = 14/2
       = 7 ✓
```

---

## **Bell Numbers B(n)**

**Definition:** Total number of partitions of n elements (into any number of subsets)

```
B(n) = Σ(k=0 to n) S(n,k)
```

**Sequence:**

```
B(0) = 1
B(1) = 1
B(2) = 2    Partitions: {1,2} or {1}|{2}
B(3) = 5    Partitions: {1,2,3}, {1,2}|{3}, {1,3}|{2}, {2,3}|{1}, {1}|{2}|{3}
B(4) = 15
B(5) = 52
B(6) = 203
B(7) = 877
```

### **Bell Triangle (Peirce Triangle)**

Construct by:

- First row: 1
- Each row starts with last element of previous row
- Each element = element to left + element above-left

```
1
1  2
2  3  5
5  7  10  15
15 20 27  37  52
52 67 87  114 151 203
```

Last element of each row gives B(n).

### **Model 2: Room Distribution**

"Assign n people to k unlabeled rooms (everyone gets a room, no empty rooms)"

### **Model 3: Ball Sorting**

"Sort n distinct balls into k identical boxes (all boxes used, no empty boxes)"

**Key:** Boxes/groups/rooms are **identical** (unlabeled)

## **Labeled vs Unlabeled Subsets**

### **Unlabeled (Stirling Numbers):**

Problem: "Partition n students into k groups"

- Groups have no names
- {Alice,Bob}|{Carol} = {Carol}|{Alice,Bob}
- Answer: **S(n,k)**

### **Labeled (Surjective Functions):**

Problem: "Assign n students to k named clubs (all clubs non-empty)"

- Clubs have identities: Club A, Club B, etc.
- Alice in Club A ≠ Alice in Club B
- Answer: **k! · S(n,k)**

**Why k!?** Each of the S(n,k) unlabeled partitions can be labeled in k! ways.

---

## **Common Mistakes to Avoid**

### **Mistake 1: Counting ordered arrangements**

❌ For {1,2,3} into 2 subsets, counting {1}|{2,3} and {2,3}|{1} separately
✓ These are the same partition (subsets unlabeled)

### **Mistake 2: Allowing empty subsets**

❌ Counting {1,2}|{3}|{} as a partition into 3 subsets
✓ All k subsets must be non-empty

### **Mistake 3: Forgetting the k! factor**

❌ Using S(n,k) when subsets are labeled
✓ Use k!·S(n,k) for labeled subsets

### **Mistake 4: Double-counting symmetric cases**

❌ For S(4,2), counting both {1,2}|{3,4} and {3,4}|{1,2}
✓ These are identical (unlabeled subsets)

# Part 2: Stirling Numbers of the First Kind

## **Core Definition**

**s(n,k)** or **c(n,k)** = The number of permutations of **n distinct elements** that have exactly *
*k disjoint cycles**.

### **Key Terms Explained**

- **Permutation:** A rearrangement/mapping of elements
- **Cycle:** A closed loop where elements map to each other
- **Disjoint:** Cycles don't share elements (each element in exactly one cycle)
- **Fixed point:** An element that maps to itself (a 1-cycle)

---

## **Understanding Permutations**

### **What is a Permutation?**

A permutation is a bijection (one-to-one mapping) from a set to itself.

**Example:** Permutation of {1,2,3,4}

**Array notation:** [2, 4, 1, 3]

This means:

```
Position 1 → value 2   (1 maps to 2)
Position 2 → value 4   (2 maps to 4)
Position 3 → value 1   (3 maps to 1)
Position 4 → value 3   (4 maps to 3)
```

**Mapping notation:**

```
1 → 2
2 → 4
3 → 1
4 → 3
```

---

## **Understanding Cycles**

### **What is a Cycle?**

A **cycle** is a chain of mappings that returns to the starting point.

**Example:** Following the mapping from 1:

```
1 → 2 → 4 → 3 → 1  (back to start!)
```

This forms one cycle: **(1 2 4 3)**

**Cycle notation** **(1 2 4 3)** means:

- 1 maps to 2
- 2 maps to 4
- 4 maps to 3
- 3 maps to 1 (loops back)

---

### **Reading Cycle Notation**

**(1 2 4 3)** reads left-to-right with wraparound:

- First element (1) → second element (2)
- Second element (2) → third element (4)
- Third element (4) → fourth element (3)
- Fourth element (3) → first element (1) [wraparound]

**Important properties:**

- **(1 2 4 3) = (2 4 3 1) = (4 3 1 2) = (3 1 2 4)** (rotation doesn't change cycle)
- Starting point in notation is arbitrary
- Usually write smallest element first

---

### **Complete Example: Finding Cycles**

**Permutation:** [3, 1, 4, 5, 2]

**Mapping:**

```
1 → 3
2 → 1
3 → 4
4 → 5
5 → 2
```

**Find cycles systematically:**

**Start with 1:**

```
1 → 3 → 4 → 5 → 2 → 1  (back to start)
```

Cycle: **(1 3 4 5 2)**

**All elements used!**

**Result:** This permutation has **1 cycle**.

---

### **Example with Multiple Cycles**

**Permutation:** [2, 1, 4, 3, 5]

**Mapping:**

```
1 → 2
2 → 1
3 → 4
4 → 3
5 → 5
```

**Find cycles:**

**Start with 1:**

```
1 → 2 → 1  (back to start)
```

Cycle: **(1 2)**
Mark 1,2 as used.

**Start with 3 (next unused):**

```
3 → 4 → 3  (back to start)
```

Cycle: **(3 4)**
Mark 3,4 as used.

**Start with 5:**

```
5 → 5  (back to start immediately)
```

Cycle: **(5)** ← This is a **fixed point**
Mark 5 as used.

**Result:** **(1 2)(3 4)(5)** → **3 cycles**

---

### **Fixed Points are 1-Cycles**

When an element maps to itself, it forms a cycle of length 1.

**Example:**

```
5 → 5
```

**Cycle notation:** **(5)**

**This counts as 1 cycle!**

The identity permutation [1,2,3,4] has:

- (1), (2), (3), (4)
- **4 cycles** (all fixed points)

---

## **Small Examples for Intuition**

### **All Permutations of {1,2,3}**

Let's find the cycle structure of all 3! = 6 permutations:

#### **1. [1,2,3] - Identity**

```
1→1, 2→2, 3→3
```

Cycles: **(1)(2)(3)** → **3 cycles**

---

#### **2. [2,1,3] - Swap first two**

```
1→2, 2→1, 3→3
```

Find cycles:

- 1→2→1: cycle **(1 2)**
- 3→3: cycle **(3)**

Cycles: **(1 2)(3)** → **2 cycles**

---

#### **3. [1,3,2] - Swap last two**

```
1→1, 2→3, 3→2
```

Find cycles:

- 1→1: cycle **(1)**
- 2→3→2: cycle **(2 3)**

Cycles: **(1)(2 3)** → **2 cycles**

---

#### **4. [3,2,1] - Swap first and last**

```
1→3, 2→2, 3→1
```

Find cycles:

- 1→3→1: cycle **(1 3)**
- 2→2: cycle **(2)**

Cycles: **(1 3)(2)** → **2 cycles**

---

#### **5. [2,3,1] - Rotate right**

```
1→2, 2→3, 3→1
```

Find cycles:

- 1→2→3→1: cycle **(1 2 3)**

Cycles: **(1 2 3)** → **1 cycle**

---

#### **6. [3,1,2] - Rotate left**

```
1→3, 2→1, 3→2
```

Find cycles:

- 1→3→2→1: cycle **(1 3 2)**

Cycles: **(1 3 2)** → **1 cycle**

---

### **Summary for n=3**

| Permutation | Array   | Cycle Notation | # Cycles |
|-------------|---------|----------------|----------|
| Identity    | [1,2,3] | (1)(2)(3)      | 3        |
| Swap 1-2    | [2,1,3] | (1 2)(3)       | 2        |
| Swap 2-3    | [1,3,2] | (1)(2 3)       | 2        |
| Swap 1-3    | [3,2,1] | (1 3)(2)       | 2        |
| Rotate →    | [2,3,1] | (1 2 3)        | 1        |
| Rotate ←    | [3,1,2] | (1 3 2)        | 1        |

**Count by cycles:**

- **3 cycles:** 1 permutation → **s(3,3) = 1**
- **2 cycles:** 3 permutations → **s(3,2) = 3**
- **1 cycle:** 2 permutations → **s(3,1) = 2**

**Verification:** 1 + 3 + 2 = 6 = 3! ✓

## **Visual Representation of Cycles**

### **Cycle (1 2 3) as a loop:**

```
    1
   ↗ ↖
  3   2
```

Follow arrows: 1→2→3→1 (one closed loop)

### **Cycles (1 2)(3 4) as separate loops:**

```
  1 ↔ 2      3 ↔ 4
```

Two independent loops

### **Cycles (1 2 3)(4) with fixed point:**

```
    1           4 (stays)
   ↗ ↖           ↓
  3   2          4
```

One 3-cycle and one fixed point

## **The Recurrence Relation**

```
s(n,k) = (n-1)·s(n-1,k) + s(n-1,k-1)
```

### **Intuition: Where Does Element n Go?**

When building a permutation of {1,2,...,n} with k cycles, focus on element **n**:

**Case 1: Element n joins an existing cycle**

- Start with permutation of {1,...,n-1} with k cycles: **s(n-1,k)** ways
- Insert n into one of the existing cycles
- Number of insertion positions: **n-1** (after each existing element)
- Total: **(n-1) · s(n-1,k)**

**Case 2: Element n forms its own cycle (fixed point)**

- Start with permutation of {1,...,n-1} with k-1 cycles: **s(n-1,k-1)** ways
- Add (n) as a new cycle
- Total: **s(n-1,k-1)**

---

### **Understanding Case 1: Insertion into Cycles**

**Example:** Insert 4 into cycle **(1 2 3)**

Original cycle: 1→2→3→1

**Position A: Insert 4 after 1**

- New mapping: 1→**4**→2→3→1
- Cycle: **(1 4 2 3)**

**Position B: Insert 4 after 2**

- New mapping: 1→2→**4**→3→1
- Cycle: **(1 2 4 3)**

**Position C: Insert 4 after 3**

- New mapping: 1→2→3→**4**→1
- Cycle: **(1 2 3 4)**

**3 insertion positions** for a 3-cycle.

Generally: **n-1 positions** for n-1 existing elements.

---

### **Why (n-1) Positions?**

In a permutation of n-1 elements, we have n-1 elements.

We can insert the new element **after** any of these n-1 elements.

**Visual:**

```
Existing elements: 1, 2, 3
Insert 4 after:    ↓  ↓  ↓
Positions:         A  B  C

3 elements → 3 positions
n-1 elements → n-1 positions
```

---

### **Detailed Example: s(4,2) = 11**

```
s(4,2) = 3·s(3,2) + s(3,1)
       = 3·3 + 2
       = 11 ✓
```

#### **Case 1: (n-1)·s(n-1,k) = 3·3 = 9 permutations**

Start with s(3,2) = 3 permutations:

1. **(1 2)(3)**
2. **(1 3)(2)**
3. **(2 3)(1)**

For each, insert 4 in 3 positions:

**From (1 2)(3):**

- Insert 4 after 1: **(1 4 2)(3)**
- Insert 4 after 2: **(1 2 4)(3)**
- Insert 4 after 3: **(1 2)(3 4)**

**From (1 3)(2):**

- Insert 4 after 1: **(1 4 3)(2)**
- Insert 4 after 3: **(1 3 4)(2)**
- Insert 4 after 2: **(1 3)(2 4)**

**From (2 3)(1):**

- Insert 4 after 2: **(2 4 3)(1)**
- Insert 4 after 3: **(2 3 4)(1)**
- Insert 4 after 1: **(2 3)(1 4)**

**Count: 3 × 3 = 9 permutations**

---

#### **Case 2: s(n-1,k-1) = s(3,1) = 2 permutations**

Start with s(3,1) = 2 permutations:

1. **(1 2 3)**
2. **(1 3 2)**

Add (4) as fixed point:

- **(1 2 3)(4)**
- **(1 3 2)(4)**

**Count: 2 permutations**

---

**Total: 9 + 2 = 11** ✓

## **Base Cases**

```
s(0,0) = 1    Empty permutation has 0 cycles
s(n,0) = 0    Non-empty permutation must have ≥1 cycle
s(0,k) = 0    Can't have 0 elements with k>0 cycles
s(n,n) = 1    Only identity: (1)(2)...(n), all fixed points
s(n,1) = (n-1)!   All elements in one cycle (circular arrangements)
s(n,k) = 0    Impossible if k > n
```

### **Special Formulas**

```
s(n,1) = (n-1)!

s(n,n-1) = C(n,2) = n(n-1)/2
```

**Proof of s(n,1) = (n-1)!:**

- One cycle means circular arrangement
- Fix element 1 at "top"
- Arrange remaining n-1: (n-1)! ways

**Proof of s(n,n-1) = C(n,2):**

- With n-1 cycles from n elements: exactly one 2-cycle, rest fixed
- Choose which 2 elements form the 2-cycle: C(n,2) ways

- s(n,n-1) = C(n,2): 1, 3, 6, 10, 15...

- 4 people at 2 circular tables
- One table with 3 people, one with 1: 8 ways

Beads on same necklace form a cycle.

## **Why s(n,k) is Harder to Visualize**

Unlike S(n,k) (partition into subsets), s(n,k) counts **structures with order**:

**Second Kind S(n,k):** Static groupings

- {1,2} is just a set
- No internal structure

**First Kind s(n,k):** Dynamic cycles

- (1 2) means 1→2→1
- Order matters within cycle
- Represents movement/flow

**Key difference:** Cycles have **direction**, subsets don't.

# Part 3: Comparison and Connections

## **Side-by-Side Comparison**

| Property            | Second Kind S(n,k)            | First Kind s(n,k)           |
|---------------------|-------------------------------|-----------------------------|
| **Definition**      | Set partitions into k subsets | Permutations with k cycles  |
| **Structure**       | Static grouping               | Dynamic mapping             |
| **Elements**        | Unlabeled subsets             | Disjoint cycles             |
| **Recurrence**      | k·S(n-1,k) + S(n-1,k-1)       | (n-1)·s(n-1,k) + s(n-1,k-1) |
| **Coefficient**     | k (# subsets to join)         | n-1 (# positions to insert) |
| **Base s/S(n,1)**   | 1                             | (n-1)!                      |
| **Base s/S(n,n)**   | 1                             | 1                           |
| **Base s/S(n,n-1)** | C(n,2)                        | C(n,2)                      |
| **Row sum**         | B(n) (Bell numbers)           | n! (all permutations)       |
| **Best analogy**    | Grouping students             | Round-table seating         |

---

## **Why Different Coefficients?**

### **Second Kind: k**

New element joins one of **k existing subsets**.

```
Subsets:  {1,2} | {3}
Add 4 to: ─┬─────┬──
           1     2  (k=2 choices)
```

### **First Kind: (n-1)**

New element inserts after one of **n-1 existing elements**.

```
Elements:   1   2   3
Insert 4:   ↓   ↓   ↓
Positions:  A   B   C  (n-1=3 positions)
```

---

## **Connection: Labeled vs Unlabeled**

### **For Subsets:**

**Unlabeled:** S(n,k) = partition into k unlabeled subsets
**Labeled:** k!·S(n,k) = assign to k named groups (surjective functions)

### **For Cycles:**

**Unlabeled:** s(n,k) = permutations with k unlabeled cycles
**Labeled:** k!·s(n,k) = permutations with k labeled cycles

Though the "labeled cycles" interpretation is less common.

---

## **Polynomial Connections**

### **Rising Factorial (Pochhammer):**

```
x^(n) = x(x+1)(x+2)···(x+n-1) = Σ(k=0 to n) S(n,k)·k!·x^k
```

### **Falling Factorial:**

```
x^(n) = x(x-1)(x-2)···(x-n+1) = Σ(k=0 to n) s̃(n,k)·x^k
```

where s̃(n,k) = (-1)^(n-k)·s(n,k) (signed Stirling numbers)

---

## **Inverse Relationship**

The matrices formed by S(n,k) and s̃(n,k) are **inverses** of each other.

This reflects the duality between:

- Converting between standard and falling factorial bases (first kind)
- Converting between standard and rising factorial bases (second kind)

# Part 4: Implementation Guide

## **Stirling Numbers of the Second Kind**

### **Method 1: DP Table**

```python
def stirling_second(n, k, MOD=10**9+7):
    """
    Compute S(n,k) using dynamic programming.
    
    Time: O(n*k)
    Space: O(n*k)
    
    Args:
        n: number of elements
        k: number of subsets
        MOD: modulo for large numbers
    
    Returns:
        S(n,k) mod MOD
    """
    # Handle base cases
    if k > n or (k == 0 and n > 0):
        return 0
    if n == 0 or k == n:
        return 1
    
    # Initialize DP table
    S = [[0] * (k+1) for _ in range(n+1)]
    
    # Base case: S(0,0) = 1
    S[0][0] = 1
    
    # Fill base cases for each row
    for i in range(1, n+1):
        S[i][0] = 0  # Can't partition n>0 into 0 subsets
        if i <= k:
            S[i][i] = 1  # Each element in own subset
    
    # Fill table using recurrence: S(n,k) = k*S(n-1,k) + S(n-1,k-1)
    for i in range(2, n+1):
        for j in range(1, min(i, k)+1):
            S[i][j] = (j * S[i-1][j] + S[i-1][j-1]) % MOD
    
    return S[n][k]
```

---

### **Method 2: Space-Optimized DP**

```python
def stirling_second_optimized(n, k, MOD=10**9+7):
    """
    Space-optimized version using O(k) space.
    
    Time: O(n*k)
    Space: O(k)
    """
    if k > n or (k == 0 and n > 0):
        return 0
    if n == 0 or k == n:
        return 1
    
    # Only keep previous and current rows
    prev = [0] * (k+1)
    curr = [0] * (k+1)
    
    prev[0] = 1  # S(0,0) = 1
    
    for i in range(1, n+1):
        curr[0] = 0  # S(i,0) = 0 for i > 0
        
        for j in range(1, min(i, k)+1):
            if i == j:
                curr[j] = 1
            else:
                curr[j] = (j * prev[j] + prev[j-1]) % MOD
        
        prev, curr = curr, prev  # Swap arrays
    
    return prev[k]
```

### **Method 3: Closed-Form (For Small k)**

```python
def stirling_second_formula(n, k, MOD=10**9+7):
    """
    Using closed-form formula via inclusion-exclusion.
    Efficient when k is small (k ≤ 20).
    
    Time: O(k log n)
    Space: O(1)
    
    Formula: S(n,k) = (1/k!) * Σ(i=0 to k) (-1)^(k-i) * C(k,i) * i^n
    """
    from math import comb
    
    result = 0
    
    # Compute sum: Σ(i=0 to k) (-1)^(k-i) * C(k,i) * i^n
    for i in range(k+1):
        sign = (-1) ** (k - i)
        term = comb(k, i) * pow(i, n, MOD)
        result = (result + sign * term) % MOD
    
    # Divide by k! (multiply by modular inverse)
    k_factorial = 1
    for i in range(1, k+1):
        k_factorial = (k_factorial * i) % MOD
    
    # Modular inverse using Fermat's Little Theorem
    # For prime MOD: a^(-1) ≡ a^(MOD-2) (mod MOD)
    k_factorial_inv = pow(k_factorial, MOD-2, MOD)
    
    result = (result * k_factorial_inv) % MOD
    
    return result
```

## **Stirling Numbers of the First Kind**

### **Method 1: DP Table**

```python
def stirling_first(n, k, MOD=10**9+7):
    """
    Compute unsigned s(n,k) using dynamic programming.
    
    Time: O(n*k)
    Space: O(n*k)
    
    Args:
        n: number of elements
        k: number of cycles
        MOD: modulo for large numbers
    
    Returns:
        s(n,k) mod MOD
    """
    # Handle base cases
    if k > n or (k == 0 and n > 0):
        return 0
    if n == 0 or k == n:
        return 1
    
    # Initialize DP table
    s = [[0] * (k+1) for _ in range(n+1)]
    
    # Base case: s(0,0) = 1
    s[0][0] = 1
    
    # Fill base cases for each row
    for i in range(1, n+1):
        s[i][0] = 0  # Can't have permutation with 0 cycles
        if i <= k:
            s[i][i] = 1  # Identity permutation
    
    # Fill table using recurrence: s(n,k) = (n-1)*s(n-1,k) + s(n-1,k-1)
    for i in range(2, n+1):
        for j in range(1, min(i, k)+1):
            s[i][j] = ((i-1) * s[i-1][j] + s[i-1][j-1]) % MOD
    
    return s[n][k]
```

### **Method 3: Signed Stirling Numbers**

```python
def stirling_first_signed(n, k, MOD=10**9+7):
    """
    Compute signed Stirling numbers: (-1)^(n-k) * s(n,k)
    
    Used in falling factorial expansions.
    """
    unsigned = stirling_first(n, k, MOD)
    
    # Compute sign: (-1)^(n-k)
    sign = 1 if (n - k) % 2 == 0 else -1
    
    return (sign * unsigned) % MOD
```

### **All S(n,k) for Fixed n**

```python
def stirling_second_row(n, MOD=10**9+7):
    """
    Compute all S(n,k) for k = 0 to n.
    
    Returns: list [S(n,0), S(n,1), ..., S(n,n)]
    """
    if n == 0:
        return [1]
    
    # Start with row 0
    prev = [1]
    
    # Build each row from previous
    for i in range(1, n+1):
        curr = [0] * (i+2)
        curr[0] = 0  # S(i,0) = 0
        curr[i] = 1  # S(i,i) = 1
        
        for j in range(1, i):
            curr[j] = (j * prev[j] + prev[j-1]) % MOD
        
        prev = curr
    
    return prev[:n+1]
```

### **Convert Permutation Array to Cycles**

```python
def permutation_to_cycles(perm):
    """
    Convert permutation array to cycle notation.
    
    Args:
        perm: list where perm[i] = where element i maps to (0-indexed)
    
    Returns:
        List of cycles, each cycle is a list
        
    Example:
        perm = [1, 0, 3, 2]  # 0→1, 1→0, 2→3, 3→2
        Returns: [[0, 1], [2, 3]]
    """
    n = len(perm)
    visited = [False] * n
    cycles = []
    
    for start in range(n):
        if visited[start]:
            continue
        
        # Follow cycle from start
        cycle = []
        curr = start
        
        while not visited[curr]:
            visited[curr] = True
            cycle.append(curr)
            curr = perm[curr]
        
        cycles.append(cycle)
    
    return cycles


def count_cycles(perm):
    """
    Count number of cycles in a permutation.
    
    Returns: k where permutation has k cycles
    """
    return len(permutation_to_cycles(perm))


# Example usage:
perm = [2, 0, 3, 1]  # 0→2→3→1→0, one 4-cycle
cycles = permutation_to_cycles(perm)
print(f"Cycles: {cycles}")  # [[0, 2, 3, 1]]
print(f"Number of cycles: {count_cycles(perm)}")  # 1
```

**Why?** S(n,k) gives unlabeled partitions, multiply by k! to assign labels.

### **Pattern 5: Exact Group Sizes**

**Problem:** Partition n items into groups of specific sizes.

**Example:** Partition 6 items into one group of 3, one of 2, and one of 1.

**Solution:** Use multinomial coefficient and divide by symmetry.

```python
def partition_with_sizes(n, sizes, MOD=10**9+7):
    """
    Partition n items into groups of given sizes.
    
    Args:
        sizes: list of group sizes (must sum to n)
    
    Example: partition_with_sizes(6, [3, 2, 1])
    """
    from math import comb
    from collections import Counter
    
    if sum(sizes) != n:
        return 0
    
    # Multinomial coefficient
    result = 1
    remaining = n
    
    for size in sizes:
        result *= comb(remaining, size)
        remaining -= size
    
    # Divide by number of identical group sizes
    size_counts = Counter(sizes)
    for count in size_counts.values():
        for i in range(1, count+1):
            result //= i
    
    return result % MOD
```

```python
def falling_factorial_coefficients(n):
    """

    return coeffs
```

### **Problem 1: Group Photo Arrangement**

**Question:** You have 10 people and 3 identical benches. Each bench must have at least one person.
How many ways can you arrange them if the order on each bench matters (left to right)?

<details>
<summary>Solution</summary>

This is NOT Stirling numbers because order on benches matters.

**Solution:**

1. Partition 10 people into 3 groups: S(10,3) ways
2. For each partition, arrange people within groups
3. If groups have sizes a, b, c: arrangements = a! × b! × c!

Total = Σ [ways to partition into sizes (a,b,c)] × a! × b! × c!

This equals **3! × S(10,3)** if benches are labeled, but needs careful computation if unlabeled.

Actually, for ordered arrangements on benches, use **surjective function** concept:
= 3! × S(10,3) when benches are labeled

With identical benches, need to sum over partition types.
</details>

**Question:** You have 7 distinct balls and 3 distinct boxes. Count the number of ways to:

## **Summary of Key Formulas**

### **Second Kind:**

```
S(n,k) = k·S(n-1,k) + S(n-1,k-1)
S(n,k) = (1/k!) Σ(i=0 to k) (-1)^(k-i) C(k,i) i^n
B(n) = Σ S(n,k)
```

### **First Kind:**

```
s(n,k) = (n-1)·s(n-1,k) + s(n-1,k-1)
s(n,1) = (n-1)!
s(n,n-1) = C(n,2)
Σ s(n,k) = n!
```

### **Conversions:**

```
Labeled subsets: k! × S(n,k)
Labeled cycles: k! × s(n,k)
```

3. **Verify base cases:** Test with small n, k
