## Module 1.1: Modulo Arithmetic Fundamentals

### Theoretical Foundation

**Concepts you must master:**

1. **Basic Modulo Properties**
   ```
   (a + b) mod m = ((a mod m) + (b mod m)) mod m
   (a - b) mod m = ((a mod m) - (b mod m) + m) mod m  [Note: +m prevents negative]
   (a × b) mod m = ((a mod m) × (b mod m)) mod m
   ```

2. **Why these properties matter:**
    - Prevents integer overflow
    - Allows breaking down large computations
    - Essential for competitive programming

3. **Common pitfalls:**
    - Forgetting to add `m` in subtraction
    - Not applying mod at every step (causes overflow)
    - Division doesn't work directly with mod (needs modular inverse)

```python
# Convert time to minutes, handle 24-hour wrap
# Key: Use modulo to handle day boundaries
def numberOfRounds(loginTime, logoutTime):
    # Convert to minutes from "HH:MM"
    def toMinutes(time):
        h, m = map(int, time.split(':'))
        return h * 60 + m

    if end < start:
```

```python
def isThree(n):
```

- Tests boundary conditions

**Solution approach:**
```python
# Perfect number: sum of proper divisors equals the number
# Optimization: only check up to sqrt(n)
def checkPerfectNumber(num):
    if num <= 1:
        return False
    
    divisor_sum = 1  # 1 is always a divisor
    
    for i in range(2, int(num ** 0.5) + 1):
        if num % i == 0:
            divisor_sum += i
            if i != num // i:  # Avoid counting sqrt twice
                divisor_sum += num // i
    
    return divisor_sum == num
```

## Module 1.2: Fast Exponentiation

### Theoretical Foundation

**Concepts you must master:**

1. **Exponentiation by Squaring**
   ```
   To compute a^n:
   - If n is even: a^n = (a^2)^(n/2)
   - If n is odd: a^n = a × a^(n-1)
   
   This reduces O(n) to O(log n)
   ```

2. **Why this works:**
   ```
   Example: 3^10
   = (3^2)^5
   = 9^5
   = 9 × 9^4
   = 9 × (9^2)^2
   = 9 × 81^2
   = 9 × 6561
   ```

3. **Iterative implementation pattern:**
   ```python
   # Template to memorize:
   def power(base, exp):
       result = 1
       while exp > 0:
           if exp % 2 == 1:  # Odd exponent
               result *= base
           base *= base      # Square the base
           exp //= 2         # Halve the exponent
       return result
   ```

### Problem Set 1.2 (3-4 days)

#### Problem 6: **50. Pow(x, n)** (Medium) ⭐⭐⭐
**Concepts needed:**
- Exponentiation by squaring
- Handling negative exponents
- Edge cases (n=0, negative base)

**Why this problem:**
- **FUNDAMENTAL** - You MUST master this
- Foundation for all modular exponentiation
- Asked frequently in interviews

**Solution approach:**
```python
# KEY INSIGHT: Use bit manipulation or recursion
# Iterative approach (preferred for interviews):
def myPow(x, n):
    if n < 0:
        x = 1 / x
        n = -n
    
    result = 1
    current_product = x
    
    while n > 0:
        if n % 2 == 1:  # If odd, multiply result
            result *= current_product
        current_product *= current_product  # Square
        n //= 2
    
    return result

# Recursive approach (easier to understand):
def myPow_recursive(x, n):
    if n == 0:
        return 1
    if n < 0:
        return 1 / myPow_recursive(x, -n)
    
    if n % 2 == 0:
        half = myPow_recursive(x, n // 2)
        return half * half
    else:
        return x * myPow_recursive(x, n - 1)
```

**Deep understanding:**
```
Why does this work?
Let's trace 2^10:

n=10 (even): result=1, base=2
  → base becomes 4, n becomes 5
n=5 (odd): result=4, base=4
  → base becomes 16, n becomes 2
n=2 (even): result=4, base=16
  → base becomes 256, n becomes 1
n=1 (odd): result=1024, base=256
  → n becomes 0

Final result = 1024 = 2^10 ✓
```

**Learning checkpoint:** Can you implement both iterative and recursive versions?

#### Problem 7: **69. Sqrt(x)** (Easy)
**Concepts needed:**
- Binary search
- Integer square root
- Overflow handling

**Why this problem:**
- Combines binary search with math
- Foundation for numerical algorithms
- Tests precision handling

**Solution approach:**
```python
# Method 1: Binary search
def mySqrt(x):
    if x < 2:
        return x
    
    left, right = 1, x // 2
    
    while left <= right:
        mid = (left + right) // 2
        square = mid * mid
        
        if square == x:
            return mid
        elif square < x:
            left = mid + 1
        else:
            right = mid - 1
    
    return right  # Return floor value

# Method 2: Newton's method (faster convergence)
def mySqrt_newton(x):
    if x < 2:
        return x
    
    guess = x
    while guess * guess > x:
        guess = (guess + x // guess) // 2
    
    return guess
```

**Learning checkpoint:** Understand why we search in [1, x//2]

#### Problem 8: **372. Super Pow** (Medium) ⭐⭐⭐
**Concepts needed:**
- Fast exponentiation with modulo
- Modular arithmetic properties
- Breaking down large exponents

**Why this problem:**
- **CRITICAL** for modular exponentiation mastery
- Pattern used in 50+ hard problems
- Tests deep understanding of mod properties

**Solution approach:**
```python
MOD = 1337

# Key insight: a^[1,2,3] = (a^[1,2])^10 × a^3
def superPow(a, b):
    def powmod(base, exp, mod):
        result = 1
        base %= mod
        while exp > 0:
            if exp % 2 == 1:
                result = (result * base) % mod
            base = (base * base) % mod
            exp //= 2
        return result
    
    if not b:
        return 1
    
    last_digit = b.pop()
    
    # Recursive breakdown: a^[1,2,3] = (a^[1,2])^10 * a^3
    part1 = powmod(superPow(a, b), 10, MOD)
    part2 = powmod(a, last_digit, MOD)
    
    return (part1 * part2) % MOD
```

**Mathematical proof:**
```
Why does this work?

a^[1,2,3] means a^123

We can write: 123 = 12 × 10 + 3
Therefore: a^123 = a^(12×10 + 3) = (a^12)^10 × a^3

This allows recursive breakdown:
- Compute a^[1,2] (which is a^12)
- Raise it to power 10
- Multiply by a^3
- All operations under modulo
```

**Learning checkpoint:** Can you explain why we use `(result * base) % mod` at each step?

#### Problem 9: **1922. Count Good Numbers** (Medium) ⭐⭐
**Concepts needed:**
- Fast exponentiation with modulo
- Combinatorial thinking
- Even/odd position handling

**Why this problem:**
- Interview-style application
- Combines multiple concepts
- Tests modular arithmetic understanding

**Solution approach:**
```python
MOD = 10**9 + 7

def countGoodNumbers(n):
    def powmod(base, exp, mod):
        result = 1
        base %= mod
        while exp > 0:
            if exp % 2 == 1:
                result = (result * base) % mod
            base = (base * base) % mod
            exp //= 2
        return result
    
    # Even positions (0, 2, 4, ...): 5 choices each (0,2,4,6,8)
    # Odd positions (1, 3, 5, ...): 4 choices each (2,3,5,7)
    
    even_count = (n + 1) // 2  # Ceiling division
    odd_count = n // 2
    
    result = powmod(5, even_count, MOD)
    result = (result * powmod(4, odd_count, MOD)) % MOD
    
    return result
```

**Deep insight:**
```
For n = 4: positions are 0,1,2,3

Position 0 (even): 5 choices
Position 1 (odd): 4 choices
Position 2 (even): 5 choices
Position 3 (odd): 4 choices

Total = 5 × 4 × 5 × 4 = 5^2 × 4^2

For n digits:
- Even positions = ⌈n/2⌉
- Odd positions = ⌊n/2⌋
```

## Module 1.3: Modular Inverse & Advanced Modular Arithmetic

### Theoretical Foundation

**Concepts you must master:**

1. **Fermat's Little Theorem**
   ```
   If p is prime and gcd(a, p) = 1:
   a^(p-1) ≡ 1 (mod p)
   ```

```python
    prime_to_num = {}
    
    for num in nums:
        factors = get_factors(num)
        for factor in factors:
            if factor in prime_to_num:
                union(num, prime_to_num[factor])
            else:
                prime_to_num[factor] = num
    
    # Count component sizes
    from collections import Counter
    return max(Counter(find(num) for num in nums).values())
```

**Algorithm breakdown:**
```
Step 1: For each number, find its prime factors
  Example: 20 → [2, 5], 30 → [2, 3, 5]

Step 2: Union numbers that share prime factors
  20 and 30 share factors 2 and 5 → union(20, 30)

Step 3: Count size of largest connected component

Time Complexity: O(N√M + Nα(N)) where M = max(nums)
  - N√M for factorization
```

### Theoretical Foundation

**Concepts you must master:**

1. **Fundamental Counting Principles**
   ```
   Addition Rule: If events are mutually exclusive:
     |A ∪ B| = |A| + |B|
   
   Multiplication Rule: If events are independent:
     |A × B| = |A| × |B|
   ```

2. **Permutations vs Combinations**
   ```
   Permutation (order matters):
     P(n, r) = n!/(n-r)! = n×(n-1)×...×(n-r+1)

     C(n, r) = n!/(r!×(n-r)!)
   
   Relationship: C(n, r) = P(n, r) / r!
   ```

3. **Pascal's Triangle & Recursion**
   ```
   C(n, r) = C(n-1, r-1) + C(n-1, r)
   
   Proof: Choosing r items from n items:
     - Case 1: Choose first item, then choose r-1 from n-1
     - Case 2: Don't choose first item, choose r from n-1
   ```

```python
def climbStairs(n):
    if n <= 2:
        return n
    
    prev2, prev1 = 1, 2
    for i in range(3, n + 1):
        current = prev1 + prev2
        prev2, prev1 = prev1, current
    
    return prev1

# Method 2: Matrix exponentiation (O(log n))
def climbStairs_matrix(n):
    def matrix_mult(A, B):
        return [[A[0][0]*B[0][0] + A[0][1]*B[1][0], A[0][0]*B[0][1] + A[0][1]*B[1][1]],
                [A[1][0]*B[0][0] + A[1][1]*B[1][0], A[1][0]*B[0][1] + A[1][1]*B[1][1]]]
    
    def matrix_power(M, n):
        if n == 1:
            return M
        if n % 2 == 0:
            half = matrix_power(M, n // 2)
            return matrix_mult(half, half)
        else:
            return matrix_mult(M, matrix_power(M, n - 1))
    
    if n <= 2:
        return n
    
    M = [[1, 1], [1, 0]]
    result = matrix_power(M, n)
    return result[0][0]
```

```
  [f(n-1)]   [1 0]   [f(n-2)]
```

**Deep mathematical insight:**
```
Let's derive the formula step by step:

For n=1: Just P1 D1 → 1 way

For n=2: We have P1,D1,P2,D2
  - P1,D1 is already placed
  - Where can we insert P2,D2?
  
  Positions: _ P1 _ D1 _  (3 gaps)
  
  If P2 in gap 1: D2 can be in gaps 2,3 → 2 ways
  If P2 in gap 2: D2 can be in gap 3 → 1 way
  If P2 in gap 3: D2 must be after → 0 ways (invalid, P2 after D1)
  
  Wait, let me reconsider...
  
  Actually: We have 4 positions: _, _, _, _
  
  Step 1: Place P1,D1
    - Choose 2 positions from 4 for P1,D1 (with P1 before D1)
    - This is C(4,2) = 6 ways... but that's not right either.
    
Let me use the recursive formula:

f(n) = ways to arrange n pickup-delivery pairs

Base: f(1) = 1

Recursive: f(n) = f(n-1) × (number of ways to insert Pn,Dn)

When we have (n-1) pairs arranged (2n-2 items):
  - There are 2n-1 gaps (before, between, and after items)
  - Choose gap for Pn: 2n-1 options
  - Choose gap for Dn (must be after Pn): depends on where Pn is

  Total options = Σ(i from 1 to 2n-1) = (2n-1)×(2n)/2

Therefore: f(n) = f(n-1) × (2n-1) × n

Simplifying:
  f(1) = 1
  f(2) = 1 × 3 × 2 = 6
  f(3) = 6 × 5 × 3 = 90
  f(n) = n! × (2n)! / (2^n)
```

```python
def waysToFillArray(queries):
    MOD = 10**9 + 7
    MAXN = 10014  # Max n + max sum of exponents
    
    # Precompute factorials and inverse factorials
    fact = [1] * MAXN
    for i in range(1, MAXN):
        fact[i] = fact[i-1] * i % MOD
    
    # Compute modular inverse using Fermat's little theorem
    inv_fact = [1] * MAXN
    inv_fact[MAXN-1] = pow(fact[MAXN-1], MOD-2, MOD)
    for i in range(MAXN-2, -1, -1):
        inv_fact[i] = inv_fact[i+1] * (i+1) % MOD
    
    def nCr(n, r):
        if r > n or r < 0:
            return 0
        return fact[n] * inv_fact[r] % MOD * inv_fact[n-r] % MOD
    
    def prime_factorize(n):
        factors = {}
        d = 2
        while d * d <= n:
            while n % d == 0:
                factors[d] = factors.get(d, 0) + 1
                n //= d
            d += 1
        if n > 1:
            factors[n] = factors.get(n, 0) + 1
        return factors
    
    result = []
    for n, k in queries:
        factors = prime_factorize(k)
        
        ans = 1
        for prime, exp in factors.items():
            # Distribute exp copies of prime into n positions
            # Using stars and bars: C(n + exp - 1, exp)
            ans = ans * nCr(n + exp - 1, exp) % MOD
        
        result.append(ans)
    
    return result
```

**Deep combinatorial insight - Stars and Bars:**
```
Problem: Distribute e identical items into n distinct boxes

This is equivalent to:
  Place e stars and (n-1) bars
  
  Example: 5 items into 3 boxes
    ** | * | **  represents [2, 1, 2]
    
  Total positions: e + (n-1)
  Choose positions for stars: C(e + n - 1, e)
  OR choose positions for bars: C(e + n - 1, n - 1)

Why this works for our problem:

k = p1^e1 × p2^e2 × ... × pm^em

For each prime p with exponent e:
  - We need to distribute e copies of p among n array elements
  - Each element can get 0 or more copies
  - This is stars and bars: C(n + e - 1, e)

Since primes are independent:
  Total ways = Π C(n + ei - 1, ei) for all primes
```

```python
        from collections import Counter
        freq = Counter(s)
        
        result = 0
        n = len(s)

                remaining = n - i - 1
                
                # Count permutations of remaining chars
                # Formula: remaining! / (freq[c1]! × freq[c2]! × ...)
                perm_count = fact[remaining]
                for count in freq.values():
                    perm_count = perm_count * inv_fact[count] % MOD
                
                result = (result + perm_count) % MOD
                freq[char] += 1  # Restore
            
            # Fix s[i] at position i and continue
            freq[s[i]] -= 1
            if freq[s[i]] == 0:
                del freq[s[i]]
        
        return result
    
    return count_permutations_less_than(s)
```

**Formula explanation:**
```
To count permutations with repetitions:

If we have n items with:
  - a1 copies of type 1
  - a2 copies of type 2
  - ...
  - ak copies of type k

Number of distinct permutations = n! / (a1! × a2! × ... × ak!)

Why?
  - Total arrangements if all distinct: n!
  - Divide by ai! for each type to account for identical items

Example: "aab"
  Total if distinct: 3! = 6
  But 'a' appears twice: 6 / 2! = 3
  Permutations: "aab", "aba", "baa" ✓
```

**Counting permutations less than given string:**
```
For string "dcba":

Position 0: How many permutations start with char < 'd'?
  - Start with 'a': remaining "dcb" → 3! permutations
  - Start with 'b': remaining "dca" → 3! permutations  
  - Start with 'c': remaining "dba" → 3! permutations
  Total from position 0: 3 × 3! = 18

Position 1 (with 'd' fixed): How many start with "d" + char < 'c'?
  - "da" + permutations of "cb" → 2! = 2
```

**Solution approach:**
```python
def numOfWays(nums):
    MOD = 10**9 + 7
    n = len(nums)
    
    # Precompute Pascal's triangle
    pascal = [[0] * n for _ in range(n)]
    for i in range(n):
        pascal[i][0] = 1
        for j in range(1, i + 1):
            pascal[i][j] = (pascal[i-1][j-1] + pascal[i-1][j]) % MOD
    
    def count_bst_arrangements(arr):
        if len(arr) <= 2:
            return 1
        
        root = arr[0]
        left = [x for x in arr if x < root]
        right = [x for x in arr if x > root]
        
        # Count arrangements of left and right subtrees
        left_ways = count_bst_arrangements(left)
        right_ways = count_bst_arrangements(right)
        
        # Ways to interleave left and right
        # Choose len(left) positions from len(left)+len(right) for left
        interleave_ways = pascal[len(left) + len(right)][len(left)]
        
        return left_ways * right_ways % MOD * interleave_ways % MOD
    
    # Subtract 1 for the original arrangement
    return (count_bst_arrangements(nums) - 1) % MOD
```

**Combinatorial insight:**
```
Why C(left + right, left)?

Given BST structure:
       root
      /    \
    left   right

The root must come first in any valid arrangement.

For the remaining elements:
  - We have (left + right) positions
  - Choose (left) positions for left subtree elements
  - Remaining positions for right subtree elements
  
The relative order within left and right must be preserved
to maintain BST structure!

Example: nums = [3,1,2,5,4,6]
  Root = 3
  Left subtree: [1,2]
  Right subtree: [5,4,6]
  
  Valid arrangements (after 3):
    [1,2,5,4,6] - left first
    [1,5,2,4,6] - interleaved
    [1,5,4,2,6] - interleaved
    [5,1,2,4,6] - interleaved
    ... and so on
    
  Total interleavings = C(5, 2) = 10
```

```python
def rearrangeSticks(n, k):
    MOD = 10**9 + 7
    
    # dp[i][j] = number of ways to arrange i sticks with j visible
    dp = [[0] * (k + 1) for _ in range(n + 1)]
    dp[0][0] = 1
    
    for i in range(1, n + 1):
        for j in range(1, min(i, k) + 1):
            # Case 1: Tallest stick at the end (visible)
            #   Remaining (i-1) sticks must have (j-1) visible
            dp[i][j] = dp[i-1][j-1]
            
            # Case 2: Tallest stick not at the end (hidden)
            #   It can be in any of (i-1) positions (not first)
            #   Remaining arrangement must have j visible
            dp[i][j] = (dp[i][j] + dp[i-1][j] * (i-1)) % MOD
    
    return dp[n][k]
```

**Deep insight - Stirling numbers:**
```

Definition: Number of permutations of n elements with exactly k cycles

Connection to our problem:

  - These are equivalent to cycles in permutation representation
  
Recurrence:
  s(n, k) = s(n-1, k-1) + (n-1) × s(n-1, k)
  
Interpretation:
  - Place largest element first: creates new cycle → s(n-1, k-1)
  - Place largest element elsewhere: merges into existing → (n-1) × s(n-1, k)

Example: n=3, k=2
  Valid arrangements: [2,1,3], [2,3,1]
  Count: s(3,2) = 3
  
  All arrangements of [1,2,3]:
    [1,2,3] → visible: 1,2,3 (k=3)
    [1,3,2] → visible: 1,3 (k=2) ✓
    [2,1,3] → visible: 2,3 (k=2) ✓
    [2,3,1] → visible: 2,3 (k=2) ✓
    [3,1,2] → visible: 3 (k=1)
    [3,2,1] → visible: 3 (k=1)
```

#### Problem 41: **260. Single Number III** (Medium) ⭐⭐
**Concepts needed:**

**Why this problem:**
- Tests XOR property mastery

**Solution approach:**
```python
def singleNumber(nums):
    # Step 1: XOR all numbers → a ⊕ b (the two unique numbers)
    xor_all = 0
    for num in nums:
        xor_all ^= num
    
    # Step 2: Find a bit where a and b differ
    # Rightmost set bit in xor_all
    diff_bit = xor_all & (-xor_all)
    
    # Step 3: Partition numbers into two groups
    a, b = 0, 0
    for num in nums:
        if num & diff_bit:
            a ^= num
        else:
            b ^= num
    
    return [a, b]
```

**Deep insight:**
```
Why does this work?

After XOR all: xor_all = a ⊕ b

The bits set in xor_all are positions where a and b differ.

Pick any such bit (we choose rightmost for simplicity).

This bit is:
  - Set in a, clear in b  OR
  - Set in b, clear in a

Partition all numbers by this bit:
  Group 1 (bit set): contains 'a' and pairs
  Group 2 (bit clear): contains 'b' and pairs

XOR each group separately:
  - Group 1: pairs cancel, left with 'a'
  - Group 2: pairs cancel, left with 'b'

Example: [1,2,1,3,2,5]
  XOR all: 1⊕2⊕1⊕3⊕2⊕5 = 3⊕5 = 011⊕101 = 110 = 6
  
  Rightmost set bit: 6 = 110 → position 1 (value 010)
  
  Partition by bit 1:
    Bit 1 set: [2,3,2] → XOR = 3
    Bit 1 clear: [1,1,5] → XOR = 5
  
  Result: [3, 5] ✓
```

```python
def subarraySum(nums, k):
    # prefix_sum -> count of times this prefix sum occurred
    prefix_count = {0: 1}  # Empty prefix
    prefix_sum = 0
    count = 0
    
    for num in nums:
        prefix_sum += num
        
        # Check if (prefix_sum - k) exists
        # If yes, we found subarray(s) with sum k
        if prefix_sum - k in prefix_count:
            count += prefix_count[prefix_sum - k]
        
        prefix_count[prefix_sum] = prefix_count.get(prefix_sum, 0) + 1

```

#### Problem 49: **907. Sum of Subarray Minimums** (Medium) ⭐⭐⭐
**Concepts needed:**

**Why this problem:**
- **HIGH-SIGNAL** (distinguishes strong candidates)

- Very common in top tech companies

**Solution approach:**
```python
def sumSubarrayMins(arr):
    MOD = 10**9 + 7
    n = len(arr)
    
    # For each element, find:
    # - left[i]: distance to previous smaller element
    # - right[i]: distance to next smaller element
    
    left = [0] * n
    right = [0] * n
    
    # Monotonic stack for left
    stack = []
    for i in range(n):
        while stack and arr[stack[-1]] > arr[i]:
            stack.pop()
        left[i] = i - stack[-1] if stack else i + 1
        stack.append(i)
    
    # Monotonic stack for right
    stack = []
    for i in range(n - 1, -1, -1):
        while stack and arr[stack[-1]] >= arr[i]:  # >= to handle duplicates
            stack.pop()
        right[i] = stack[-1] - i if stack else n - i
        stack.append(i)
    
    # Calculate contribution of each element
    result = 0
    for i in range(n):
        result = (result + arr[i] * left[i] * right[i]) % MOD
    
    return result
```

**Contribution technique insight:**
```
Instead of iterating through all O(n²) subarrays,
count how many subarrays have arr[i] as minimum!

For arr[i] to be minimum in subarray [l, r]:
  - All elements in [l, i-1] must be >= arr[i]
  - All elements in [i+1, r] must be >= arr[i]

left[i] = number of elements to the left (including i) where arr[i] is min
right[i] = number of elements to the right (including i) where arr[i] is min

Total subarrays with arr[i] as min = left[i] × right[i]
Contribution = arr[i] × left[i] × right[i]

Example: arr = [3,1,2,4]
  For arr[1] = 1:
    left[1] = 2  (can extend to index 0)
    right[1] = 3 (can extend to indices 2,3)
    Contribution: 1 × 2 × 3 = 6
    
    Subarrays: [3,1], [1], [1,2], [1,2,4], [3,1,2], [3,1,2,4]
    Count: 6 ✓
```

```python
def maxSumMinProduct(nums):
    MOD = 10**9 + 7
    n = len(nums)
    
    # Build prefix sum
    prefix = [0] * (n + 1)
    for i in range(n):
        prefix[i + 1] = prefix[i] + nums[i]

    left = [-1] * n

    for i in range(n):
```

```python
def consecutiveNumbersSum(n):
    # n = k + (k+1) + (k+2) + ... + (k+m-1)
    # n = m*k + (0+1+2+...+(m-1))
    # n = m*k + m*(m-1)/2
    # 2n = m*(2k + m - 1)
    
    count = 0
    
    # Iterate through possible lengths m
    m = 1
    while m * (m - 1) // 2 < n:
        # Check if we can form sum with length m
        # 2n = m * (2k + m - 1)
        # 2n = m * something
        # something = 2k + m - 1 must be odd/even accordingly
        
        numerator = 2 * n - m * (m - 1)
        if numerator % (2 * m) == 0:
            count += 1
        
        m += 1
    
    return count
```

**Mathematical derivation:**
```
Sum of m consecutive numbers starting at k:
  k + (k+1) + ... + (k+m-1)
  = m*k + (0+1+...+(m-1))
  = m*k + m*(m-1)/2

Set equal to n:
  n = m*k + m*(m-1)/2

Solve for k:
  k = (n - m*(m-1)/2) / m
  k = n/m - (m-1)/2

For k to be positive integer:
  1. n/m - (m-1)/2 must be positive integer
  2. n - m*(m-1)/2 must be divisible by m

Or equivalently:
  2n = m*(2k + m - 1)

For valid k >= 1:
  2k + m - 1 >= m
  2k >= 1
  k >= 1 (always true if integer)

So we need:
  (2n - m*(m-1)) % (2m) == 0

Example: n = 15
  m=1: 15 = 15 ✓
  m=2: 15 = 7+8 ✓
  m=3: 15 = 4+5+6 ✓
  m=4: Not possible
  m=5: 15 = 1+2+3+4+5 ✓
  
  Count = 4 ✓
```

#### Problem 53: **1808. Maximize Number of Nice Divisors** (Hard) ⭐⭐
**Concepts needed:**

**Why this problem:**
- Tests deep mathematical reasoning
- Optimization without calculus
- Common in algorithmic rounds

**Solution approach:**
```python
def maxNiceDivisors(primeFactors):
    MOD = 10**9 + 7
    
    if primeFactors <= 3:
        return primeFactors
    
    # Maximize product: split into 3's as much as possible
    # Why 3? AM-GM inequality shows 3 is optimal
    
    if primeFactors % 3 == 0:
        return pow(3, primeFactors // 3, MOD)
    elif primeFactors % 3 == 1:
        # Better to use 2*2 instead of 3*1
        return pow(3, (primeFactors - 4) // 3, MOD) * 4 % MOD
    else:  # primeFactors % 3 == 2
        return pow(3, primeFactors // 3, MOD) * 2 % MOD
```

**Mathematical proof:**
```
Goal: Split n into positive integers to maximize product

AM-GM Inequality:
  (a1 + a2 + ... + ak) / k >= (a1 * a2 * ... * ak)^(1/k)

For fixed sum, product is maximized when all parts are equal!

What value should parts be?

Let sum = n, each part = x, number of parts = n/x
  Product = x^(n/x)

To maximize x^(n/x), take derivative of ln(product):
  d/dx [n/x * ln(x)] = n/x * (1/x - ln(x)/x²) = 0
  1 - ln(x) = 0
  ln(x) = 1
  x = e ≈ 2.718

Since we need integers, test x = 2 and x = 3:
  2^(n/2) vs 3^(n/3)
  
  Take ln: (n/2)*ln(2) vs (n/3)*ln(3)
           n*ln(2)/2 vs n*ln(3)/3
           ln(2)/2 = 0.347 vs ln(3)/3 = 0.366
  
Therefore: 3 is better than 2!

But what about x = 4?
  4 = 2*2, so splitting 4 into 2*2 gives same product
  But 4 = 3+1, and 3*1 = 3 < 4
  So 3 is still better!

Conclusion: Use as many 3's as possible
  - If remainder 0: all 3's
  - If remainder 1: replace last 3+1 with 2+2 (since 4 > 3)
  - If remainder 2: one 2 at the end
```

```python
class Fancy:
    def __init__(self):
        self.MOD = 10**9 + 7
        self.seq = []
        self.add_val = 0
        self.mult_val = 1
    
    def append(self, val):
        # Store the "base" value by reversing current operations
        # base × mult + add = val (mod MOD)
        # base = (val - add) × mult^(-1) (mod MOD)
        
        inv_mult = pow(self.mult_val, self.MOD - 2, self.MOD)
        base = (val - self.add_val) * inv_mult % self.MOD
        self.seq.append(base)
    
    def addAll(self, inc):
        self.add_val = (self.add_val + inc) % self.MOD
    
    def multAll(self, m):
        self.mult_val = (self.mult_val * m) % self.MOD
        self.add_val = (self.add_val * m) % self.MOD
    
    def getIndex(self, idx):
        if idx >= len(self.seq):
            return -1
        
        # Apply current operations to base value
        base = self.seq[idx]
        return (base * self.mult_val + self.add_val) % self.MOD
```

```
On addAll(inc):

On multAll(m):

On append(val):
```

```python
def idealArrays(n, maxValue):
    MOD = 10**9 + 7
    
    # Precompute factorials
    fact = [1] * (n + 14)
    for i in range(1, n + 14):
        fact[i] = fact[i-1] * i % MOD
    
    inv_fact = [1] * (n + 14)
    inv_fact[n + 13] = pow(fact[n + 13], MOD - 2, MOD)
    for i in range(n + 12, -1, -1):
        inv_fact[i] = inv_fact[i + 1] * (i + 1) % MOD
    
    def nCr(n, r):
        if r > n or r < 0:
            return 0
        return fact[n] * inv_fact[r] % MOD * inv_fact[n - r] % MOD
    
    # Count for each possible last value
    result = 0
    
    for last_val in range(1, maxValue + 1):
        # Factorize last_val
        factors = {}
        temp = last_val
        d = 2
        while d * d <= temp:
            while temp % d == 0:
                factors[d] = factors.get(d, 0) + 1
                temp //= d
            d += 1
        if temp > 1:
            factors[temp] = factors.get(temp, 0) + 1
        
        # For each prime factor with exponent e:
        # Distribute e "increments" across n positions
        # Each position can have 0 to e increments
        
        ways = 1
        for prime, exp in factors.items():
            # Stars and bars: place exp items in n positions
            # Also, items must form non-decreasing sequence
            # This is: C(n + exp - 1, exp)
            ways = ways * nCr(n + exp - 1, exp) % MOD
        
        result = (result + ways) % MOD
    
    return result
```

```
This is equivalent to:
  - Distribute e "increments" among n positions
  - Each position can get 0 or more increments

This is stars and bars: C(n + e - 1, e)

  Total ways = Π C(n + ei - 1, ei)
```

#### Problem 58: **1671. Minimum Number of Removals to Make Mountain Array** (Hard) ⭐⭐
**Concepts needed:**

- Combining results

**Why this problem:**
- Tests DP combination technique

**Solution approach:**
```python
def minimumMountainRemovals(nums):
    n = len(nums)
    
    # LIS ending at each position
    lis = [1] * n
    for i in range(n):
        for j in range(i):
            if nums[j] < nums[i]:
                lis[i] = max(lis[i], lis[j] + 1)
    
    # LDS (Longest Decreasing Subsequence) starting at each position
    lds = [1] * n
    for i in range(n - 1, -1, -1):
        for j in range(i + 1, n):
            if nums[j] < nums[i]:
                lds[i] = max(lds[i], lds[j] + 1)
    
    # Find maximum mountain length
    max_mountain = 0
    for i in range(1, n - 1):
        # Peak must have both increasing and decreasing parts
        if lis[i] > 1 and lds[i] > 1:
            mountain_length = lis[i] + lds[i] - 1
            max_mountain = max(max_mountain, mountain_length)
    
    return n - max_mountain
```

**Mountain array insight:**
```
Mountain array: strictly increasing then strictly decreasing
  Example: [1,3,5,4,2]

Strategy: Find longest mountain subsequence, remove rest

For each potential peak i:
  - LIS[i] = longest increasing subsequence ending at i
  - LDS[i] = longest decreasing subsequence starting at i
  - Mountain length at peak i = LIS[i] + LDS[i] - 1
  (subtract 1 because peak counted twice)

Requirements:
  - LIS[i] > 1 (has increasing part)
  - LDS[i] > 1 (has decreasing part)

Example: [2,1,1,5,6,2,3,1]
  LIS: [1,1,1,2,3,2,3,1]
  LDS: [1,1,1,3,3,2,2,1]
  
  Check each peak:
    i=4: LIS=3, LDS=3 → mountain=5 ✓
```

#### Problem 60: **2sum, 3sum, 4sum** Series with Modular Arithmetic Extensions

**Extension problem (not on LeetCode):**
"Given array nums and target k, find pairs (i,j) where (nums[i] + nums[j]) % k == target"

**Solution approach:**
```python
def twoSumMod(nums, k, target):
    count = 0
    remainder_count = {}
    
    for num in nums:
        remainder = num % k
        
        # What remainder do we need to pair with?
        needed = (target - remainder + k) % k
        
        count += remainder_count.get(needed, 0)
        remainder_count[remainder] = remainder_count.get(remainder, 0) + 1
    
    return count
```

**Three sum with modulo:**
```python
def threeSumMod(nums, k, target):
    n = len(nums)
    count = 0
    
    for i in range(n):
        # Fix nums[i], find pairs that sum to (target - nums[i]) mod k
        seen = {}
        needed_total = (target - nums[i] % k + k) % k
        
        for j in range(i + 1, n):
            remainder = nums[j] % k
            complement = (needed_total - remainder + k) % k
            
            count += seen.get(complement, 0)
            seen[remainder] = seen.get(remainder, 0) + 1
    
    return count
```

## Master Template Library

### 1. Fast Exponentiation with Modulo
```python
def pow_mod(base, exp, mod):
    result = 1
    base %= mod
    while exp > 0:
        if exp % 2 == 1:
            result = (result * base) % mod
        base = (base * base) % mod
        exp //= 2
    return result
```

### 2. GCD (Euclidean Algorithm)
```python
def gcd(a, b):
    while b:
        a, b = b, a % b
    return a

def lcm(a, b):
    return (a * b) // gcd(a, b)
```

### 3. Sieve of Eratosthenes
```python
def sieve(n):
    is_prime = [True] * (n + 1)
    is_prime[0] = is_prime[1] = False
    
    for i in range(2, int(n**0.5) + 1):
        if is_prime[i]:
            for j in range(i*i, n + 1, i):
                is_prime[j] = False
    
    return [i for i in range(n + 1) if is_prime[i]]
```

### 4. Prime Factorization
```python
def prime_factors(n):
    factors = {}
    d = 2
    while d * d <= n:
        while n % d == 0:
            factors[d] = factors.get(d, 0) + 1
            n //= d
        d += 1
    if n > 1:
        factors[n] = factors.get(n, 0) + 1
    return factors
```

### 5. nCr with Modulo
```python
# Precompute factorials
MOD = 10**9 + 7
MAXN = 100001

fact = [1] * MAXN
for i in range(1, MAXN):
    fact[i] = fact[i-1] * i % MOD

inv_fact = [1] * MAXN
inv_fact[MAXN-1] = pow(fact[MAXN-1], MOD-2, MOD)
for i in range(MAXN-2, -1, -1):
    inv_fact[i] = inv_fact[i+1] * (i+1) % MOD

def nCr(n, r):
    if r > n or r < 0:
        return 0
    return fact[n] * inv_fact[r] % MOD * inv_fact[n-r] % MOD
```

```python
def subarray_sum_k(nums, k):
    prefix_count = {0: 1}
    prefix_sum = 0
    count = 0
    
    for num in nums:
        prefix_sum += num
        if prefix_sum - k in prefix_count:
```

### 8. Contribution Technique with Monotonic Stack
```python
def sum_subarray_mins(arr):
    MOD = 10**9 + 7
    n = len(arr)
    
    # Find previous and next smaller elements
    left = [0] * n
    right = [0] * n
    
    stack = []
    for i in range(n):
        while stack and arr[stack[-1]] > arr[i]:
            stack.pop()
        left[i] = i - stack[-1] if stack else i + 1
        stack.append(i)
    
    stack = []
    for i in range(n-1, -1, -1):
        while stack and arr[stack[-1]] >= arr[i]:
            stack.pop()
        right[i] = stack[-1] - i if stack else n - i
        stack.append(i)
    
    result = 0
    for i in range(n):
        result = (result + arr[i] * left[i] * right[i]) % MOD
    
    return result
```
