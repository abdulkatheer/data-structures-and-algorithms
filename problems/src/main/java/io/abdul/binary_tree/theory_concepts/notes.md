# Definition

Binary Tree -> All nodes in the tree should have at most 2 children (0, 1 or 2)

## Concepts

Root: The starting point of the tree. Doesn't have any parent.
Child: Has a parent node
Parent: Has 1 or 2 children and for them this is the parent
Ancestors: Parent and Grand parents of a node
Leaf: A node which doesn't have any children

# Types

## Full Binary Tree

All nodes in the tree should either have 0 or 2 nodes. No node with a single child should exist;

## Complete Binary Tree

- All levels except the last level should be filled (have 2 children for each)
- The last level should be filled from the left

## Perfect Binary Tree

All levels should be filled. No gaps anywhere.

## Balanced Binary Tree

The difference between the height of the left and right subtree should not be more than 1.

## Degenerate Tree

Tree having nodes only on the left side or on the right side.
Skewed on the left or on the right.

# Traversal

2) preorder
3) postorder
4) level order
