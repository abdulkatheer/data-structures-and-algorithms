## Monotonic - meaning

- Adjective
- Sound -> maintaining a same note during a speech without going higher or lower
- Quantity -> only ever-increasing, or ever-decreasing

## Monotonic Stack

Elements of the stack will be monotonic!
When we add an element, we make sure monotonic property is maintained
If increasing, when we add, we remove every element which is larger or equals the new element
If decreasing, when we add, we remove every element which is smaller or equals the new element
