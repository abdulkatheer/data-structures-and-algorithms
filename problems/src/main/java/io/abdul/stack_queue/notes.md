  organized in memory.
- Everything else is custom data structures built for specific purpose. Like Stack, Queue, HashMap
  etc.,
- Stack - LIFO
- Queue - FIFO

# Monotonic Stack

- Elements of the stack will follow a specific order, every increasing or every decreasing, and may
  include flat values as well
- This looks simple but helps solve a lot of complex problems

## Foundations

- Next greater element - Decreasing stack
- Next greater or equals element - Decreasing or flat stack
- Previous greater element - Decreasing stack
- Previous greater or equals element - Decreasing or flat stack
- Next smaller element - Increasing stack
- Previous smaller element - Increasing stack

## Advanced

- Sum of subarray mins
- Sum of subarray maxs
- Sum of subarray ranges (max-min)
